Introducción a Linux
Qué es, por qué aprenderlo y dónde se usa

Linux es un sistema operativo de código abierto basado en Unix. Es el sistema que corre en la gran mayoría de servidores del mundo, en Android, en la nube (AWS, GCP, Azure) y en supercomputadoras. Como desarrollador web, vas a trabajar con Linux tarde o temprano.

🟢 ¿Cuál aprender primero?

Ubuntu es la recomendación para empezar. Tiene la comunidad más grande, más tutoriales, y los comandos son iguales en todas las distros basadas en Debian. Lo que aprendes en Ubuntu funciona en los servidores más comunes del mundo real.

Linux vs Windows — la mentalidad diferente

🐧 Linux
  • ✦ Todo es un archivo (incluso los dispositivos)
  • ✦ La terminal es el centro de todo
  • ✦ Minúsculas y mayúsculas importan (File ≠ file)
  • ✦ Rutas con / (diagonal)
  • ✦ Sin extensiones obligatorias
🪟 Windows
  • ✦ Interfaz gráfica como centro
  • ✦ CMD/PowerShell son secundarios
  • ✦ No distingue mayúsculas (File = file)
  • ✦ Rutas con \ (contrabarra)
  • ✦ Extensiones obligatorias (.exe, .txt)

Sistema de Archivos de Linux
Todo parte de / — la raíz del sistema

En Linux no hay letras de disco (C:, D:). Todo el sistema de archivos parte de un único punto raíz llamado / (slash). A partir de ahí todo es una carpeta o un archivo.

/ # raíz — todo parte de aquí ├── bin/ # binarios esenciales: ls, cp, mv, bash ├── boot/ # archivos del arranque del sistema ├── dev/ # dispositivos (disco, teclado, mouse) ├── etc/ # configuración del sistema y programas ├── home/ # carpetas personales de usuarios │ ├── hugo/ # tu carpeta home — aquí vive tu trabajo │ └── otro-usuario/ ├── lib/ # librerías compartidas del sistema ├── media/ # USB, discos externos montados ├── opt/ # software opcional instalado manualmente ├── proc/ # info de procesos en tiempo real ├── root/ # home del superusuario (root) ├── tmp/ # archivos temporales (se borran al reiniciar) ├── usr/ # programas y utilidades del usuario │ └── bin/ # la mayoría de programas instalados van aquí └── var/ # datos variables: logs, bases de datos, emails

Rutas absolutas vs relativas

TipoEjemploCuándo usarla
Absoluta/home/hugo/proyectos/index.htmlParte siempre desde /. Funciona desde cualquier lugar.
Relativaproyectos/index.htmlParte desde donde estás ahora. Más corta y práctica.

Atajos de ruta esenciales

~
Tu carpeta home. Equivale a /home/tu-usuario
cd ~ → va a /home/hugo
.
El directorio actual (donde estás ahora)
./script.sh → ejecuta script aquí
..
El directorio padre (un nivel arriba)
cd .. → sube un nivel
-
El directorio anterior (el último donde estuviste)
cd - → vuelve al directorio anterior

La Shell — El intérprete de comandos
El programa que traduce lo que escribes en acciones del sistema

La shell es el programa que recibe los comandos que escribes, los interpreta y le dice al sistema operativo qué hacer. La terminal es la ventana; la shell es el programa que corre dentro de ella.

bash — hugo@ubuntu: ~
# El prompt: lo que aparece antes de que escribas hugo@ubuntu:~$ ← esto es el prompt # │ │ │ └─ $ = usuario normal # = root (admin) # │ │ └─── ~ = directorio actual (home) # │ └─────── nombre del equipo (hostname) # └────────────── tu nombre de usuario hugo@ubuntu:~$ echo "Hola Linux" Hola Linux

🟢 ¿Cómo saber qué shell estás usando?

Escribe echo $SHELL y el sistema te dirá cuál es tu shell activa. Por ejemplo: /bin/bash o /usr/bin/zsh.

anatomía de un comando

El comando ls en detalle — el más usado

ls y sus opciones
$ ls Documentos Descargas Escritorio proyectos foto.jpg $ ls -l # formato largo: permisos, tamaño, fecha drwxr-xr-x 2 hugo hugo 4096 jun 15 10:30 Documentos -rw-r--r-- 1 hugo hugo 2048 jun 14 09:15 foto.jpg $ ls -a # muestra archivos ocultos (empiezan con .) . .. .bashrc .config Documentos proyectos $ ls -la # combina -l y -a (el más completo) drwxr-xr-x 8 hugo hugo 4096 jun 15 10:30 . drwxr-xr-x 32 root root 4096 jun 10 08:00 .. -rw-r--r-- 1 hugo hugo 220 jun 1 12:00 .bashrc drwxr-xr-x 2 hugo hugo 4096 jun 15 10:30 Documentos $ ls -lh # -h = human readable (KB, MB, GB en vez de bytes) -rw-r--r-- 1 hugo hugo 2.0K jun 14 foto.jpg $ ls -lt # ordena por fecha de modificación (más reciente primero) $ ls /var/log # lista contenido de otra carpeta sin ir a ella

El comando cd en detalle

cd y sus variantes
$ cd Documentos # entra a Documentos (ruta relativa) $ cd /var/log # va directo a /var/log (ruta absoluta) $ cd ~ # va a tu home sin importar dónde estés $ cd # sin argumento = igual que cd ~ $ cd .. # sube un nivel (al directorio padre) $ cd ../.. # sube dos niveles $ cd - # vuelve al directorio anterior $ cd "Mi carpeta" # comillas si el nombre tiene espacios

Crear, copiar, mover y borrar
Las operaciones fundamentales sobre archivos y directorios
mkdir
MaKe DIRectory
Crea uno o varios directorios
$ mkdir proyectos / $ mkdir -p a/b/c
touch
Touch
Crea un archivo vacío o actualiza su fecha
$ touch index.html / $ touch a.txt b.txt
cp
CoPy
Copia archivos o directorios
$ cp origen.txt destino.txt
mv
MoVe
Mueve o renombra archivos y directorios
$ mv viejo.txt nuevo.txt
rm
ReMove
Elimina archivos o directorios (¡sin papelera!)
$ rm archivo.txt / $ rm -rf carpeta/
rmdir
ReMove DIRectory
Elimina directorios vacíos únicamente
$ rmdir carpeta-vacia/

Estos comandos en acción

mkdir, touch, cp, mv, rm
# CREAR $ mkdir mi-proyecto # crea carpeta $ mkdir -p src/css/components # crea árbol completo de una vez $ touch index.html style.css app.js # crea 3 archivos vacíos # COPIAR $ cp index.html backup.html # copia archivo $ cp -r src/ src-backup/ # -r para copiar carpetas $ cp *.html backup/ # copia todos los .html a backup/ # MOVER / RENOMBRAR $ mv viejo.txt nuevo.txt # renombra $ mv index.html src/ # mueve a la carpeta src/ $ mv carpeta/ otro-lugar/ # mueve carpeta entera # ELIMINAR $ rm archivo.txt # elimina archivo $ rm -r carpeta/ # elimina carpeta y su contenido $ rm -rf carpeta/ # -f fuerza sin pedir confirmación $ rm *.log # elimina todos los archivos .log

⚠️ rm -rf no tiene marcha atrás

En Linux no hay papelera de reciclaje en la terminal. El comando rm -rf elimina archivos permanentemente sin preguntar. Siempre verifica dos veces antes de ejecutarlo — especialmente con rutas que contengan variables o comodines. El famoso rm -rf / borraría todo el sistema.

find — el más poderoso

find en acción
# Buscar por nombre $ find . -name "index.html" # busca en . (aquí) por nombre exacto $ find /home -name "*.js" # todos los .js en /home $ find . -iname "*.HTML" # -iname ignora mayúsculas/minúsculas # Buscar por tipo $ find . -type f # solo archivos (f = file) $ find . -type d # solo directorios (d = directory) # Buscar por tamaño $ find . -size +1M # archivos mayores a 1 megabyte $ find . -size -10k # archivos menores a 10 kilobytes # Buscar y ejecutar acción $ find . -name "*.log" -delete # busca y elimina todos los .log

Ejercicio — Explorar y construir en la terminal
Practica los comandos de la Parte A en secuencia
✏️ Ejercicio Parte A Principiante

Abre tu terminal y ejecuta los siguientes pasos en orden:

  1. Ejecuta pwd para saber dónde estás. Después whoami y uname -a.
  2. Ve a tu home con cd ~ y lista su contenido con ls -la.
  3. Crea esta estructura de carpetas de una sola vez:
    mkdir -p practica-linux/src/css practica-linux/src/js practica-linux/docs
  4. Entra a practica-linux/ con cd practica-linux y verifica con pwd.
  5. Crea estos archivos vacíos: touch index.html README.md
  6. Crea un archivo en subcarpeta: touch src/css/style.css src/js/app.js
  7. Lista todo el árbol con ls -la y si tienes tree instalado: tree
  8. Copia el README: cp README.md docs/README-backup.md
  9. Renombra index.html: mv index.html home.html
  10. Busca todos los archivos .html dentro del proyecto: find . -name "*.html"
  11. Consulta el manual de ls: man ls (presiona q para salir)
  12. Limpia la pantalla con clear y mira tu historial con history

🟢 Resumen de la Parte A

  • Linux: sistema de código abierto, base de servidores y la nube. Todo parte de /
  • Carpetas clave: /home (usuarios), /etc (configs), /var (logs), /tmp (temporales)
  • Rutas: absolutas (desde /) y relativas (desde donde estás). Atajos: ~, ., .., -
  • La shell interpreta los comandos. El prompt muestra: usuario@host:directorio$
  • Estructura: comando [flags] [argumentos]
  • pwd — dónde estás · ls -la — lista detallada · cd — cambia directorio
  • mkdir -p — crea árbol · touch — crea archivo vacío
  • cp -r — copia (con carpetas) · mv — mueve/renombra · rm -rf — elimina sin papelera
  • find . -name "*.html" — busca archivos · man comando — ayuda completa
  • whoami, uname -a, df -h, free -h — información del sistema
