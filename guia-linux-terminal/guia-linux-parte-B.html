Comando cat — Leer y concatenar archivos
38:18 — El comando más directo para ver el contenido de un archivo

cat (conCATenate) lee el contenido de uno o varios archivos y lo imprime en la terminal. Es perfecto para archivos cortos. Para archivos largos, usa less.

cat en acción
# VER contenido de un archivo $ cat index.html <!DOCTYPE html> <html lang="es"> <head>...</head> </html> # VER con números de línea $ cat -n index.html 1 <!DOCTYPE html> 2 <html lang="es"> # VER varios archivos seguidos $ cat archivo1.txt archivo2.txt # CREAR un archivo escribiendo en la terminal # (Ctrl+D para terminar) $ cat > notas.txt Esto es una nota que escribo directamente ^D # CONCATENAR archivos en uno nuevo $ cat parte1.txt parte2.txt > completo.txt # AGREGAR contenido al final de un archivo (sin sobreescribir) $ cat extra.txt >> completo.txt # VER fin de línea y tabulaciones ocultas $ cat -A archivo.txt

🟢 > vs >> — la diferencia crítica

  • > — redirige y sobreescribe. Si el archivo existe, borra su contenido y escribe de nuevo.
  • >> — agrega al final. Si el archivo existe, conserva el contenido y añade al final.
📜
Comando less — Leer archivos largos con navegación
38:18 — El paginador que todo desarrollador usa para logs y archivos grandes

less abre un archivo en modo de lectura interactiva — puedes desplazarte hacia arriba y abajo sin cargar todo en pantalla. Es el comando estándar para leer logs y archivos largos. "less is more" — es mejor que el antiguo comando more.

less
$ less archivo-largo.txt $ less /var/log/syslog # log del sistema $ less -N archivo.txt # con números de línea

Controles dentro de less

↑ / ↓Desplazarse línea a línea
Space / bPágina siguiente / página anterior
gIr al inicio del archivo
GIr al final del archivo
/textoBuscar texto hacia adelante
?textoBuscar texto hacia atrás

NCoincidencia anterior de la búsqueda

head y tail — alternativas para ver partes de un archivo

head y tail
# head: muestra las primeras líneas $ head archivo.txt # primeras 10 líneas (por defecto) $ head -n 20 archivo.txt # primeras 20 líneas $ head -5 archivo.txt # primeras 5 (forma corta) # tail: muestra las últimas líneas $ tail archivo.txt # últimas 10 líneas $ tail -n 20 archivo.txt # últimas 20 líneas # tail -f: SIGUE el archivo en tiempo real (logs en vivo) $ tail -f /var/log/syslog # muestra nuevas líneas conforme aparecen # Ctrl+C para detener

🟢 tail -f es el comando que más usarás en el trabajo

Cuando depuras una aplicación en un servidor, tail -f /var/log/tu-app.log te muestra los errores y eventos en tiempo real mientras la app está corriendo. Es indispensable para debugging en producción.

Editor nano — El editor amigable de la terminal
44:40 — Editar archivos directamente en la terminal, sin complicaciones

nano es un editor de texto que vive dentro de la terminal. Es simple e intuitivo — todos los atajos se muestran en pantalla. Es el editor recomendado para principiantes y para ediciones rápidas en servidores.

abrir nano
$ nano archivo.txt # abre o crea el archivo $ nano +20 archivo.txt # abre en la línea 20 $ nano -l archivo.txt # muestra números de línea

Atajos esenciales de nano

El símbolo ^ significa Ctrl. Por ejemplo, ^X = Ctrl+X.

^XSalir (pregunta si guardar si hay cambios)
^OGuardar el archivo (WriteOut)
^WBuscar texto (Where is)
^\Buscar y reemplazar
^KCortar la línea actual (Cut)
^UPegar la línea cortada (Uncut)
^AIr al inicio de la línea
^EIr al final de la línea
^CVer número de línea y columna actuales
^GAyuda completa (Get help)
Alt+UDeshacer (Undo)
Alt+ERehacer (Redo)

🟢 Flujo típico en nano

Abres con nano archivo.txt → escribes/editas → Ctrl+O para guardar → Enter para confirmar el nombre → Ctrl+X para salir. Eso es todo lo que necesitas para el 90% de los casos.

Editor vi / vim — El editor modal de la terminal
50:08 — El más poderoso y el más temido. Una vez que lo dominas, no hay nada igual.

vi está instalado en absolutamente todos los sistemas Unix/Linux — es el editor de emergencia que siempre va a estar disponible cuando conectas a un servidor. vim (Vi IMproved) es su versión mejorada con más funciones. La diferencia con nano: vi tiene modos.

abrir vi / vim
$ vi archivo.txt # abre con vi $ vim archivo.txt # abre con vim (recomendado) $ vim +20 archivo.txt # abre en la línea 20

Los modos de vi — la clave de todo

NORMAL (por defecto)

Al abrir vi entras aquí. No puedes escribir texto. Es para navegar y ejecutar comandos. Presiona Esc para volver aquí.

INSERT (escritura)

Aquí puedes escribir texto. Entras presionando i, a, o u otras teclas desde el modo Normal. Ves -- INSERT -- abajo.

COMMAND (comandos)

Para guardar, salir, buscar y más. Entras desde Normal presionando :. Los comandos aparecen abajo.

Así se ve vim por dentro

VIM — archivo.txt 1,1 — Todo
1function saludar() {
2 const msg = "Hola desde vi";
3 console.log(msg);
4}
5// Modo NORMAL — no puedes escribir
6// Presiona i para entrar en modo INSERT
-- NORMAL --                            1,1     Todo

Editar en modo NORMAL

Comandos de GUARDADO Y SALIDA (modo Command con :)

:wGuardar (write)
:qSalir (quit) — solo si no hay cambios
:wqGuardar y salir (el más usado)
:q!Salir SIN guardar (forzado)
:wq!Guardar y salir forzado (si el archivo es readonly)
ZZGuardar y salir (atajo sin los dos puntos)

⚡ El chiste de "cómo salir de vi"

Es uno de los chistes más famosos en programación — miles de personas quedan atrapados en vi sin poder salir. La respuesta: presiona Esc para asegurarte de estar en modo Normal, luego escribe :q! y Enter para salir sin guardar, o :wq para guardar y salir.

🟢 ¿Cuándo aprender vim en serio?

Para tareas básicas en servidor, nano es suficiente. Aprende vim cuando quieras un editor ultrarrápido para tu trabajo diario. Con los plugins adecuados (NeoVim + configuración) supera en velocidad a cualquier IDE. Muchos desarrolladores senior editan exclusivamente en vim.

¿Qué son exactamente los comandos?
58:08 — Los 4 tipos de comandos que existen en Linux

Cuando escribes un comando en la terminal, la shell necesita saber qué tipo de cosa es ese comando para poder ejecutarlo. Hay exactamente 4 tipos.

1. Ejecutables
ls, cp, git, node, python
Programas compilados o scripts que están en el disco, normalmente en /usr/bin o /bin. La shell los busca en las rutas del PATH.
2. Builtins de la shell
cd, echo, pwd, export, source
Comandos que viven dentro de la propia shell (bash, zsh). No son programas externos — son parte del intérprete. Por eso cd no tiene un archivo en /bin.
3. Funciones de shell
funciones definidas en .bashrc
Bloques de código que defines tú mismo en archivos de configuración como ~/.bashrc. Funcionan como comandos pero son tuyas.
4. Alias
ll, gs, la (los que definas)
Atajos — palabras cortas que la shell reemplaza por comandos más largos antes de ejecutarlos. Son los más útiles para productividad.

El comando type — descubre qué tipo es cada comando

type en acción
$ type ls ls is /usr/bin/ls # ejecutable en /usr/bin $ type cd cd is a shell builtin # builtin de bash $ type ll ll is aliased to `ls -alF' # alias $ type node node is /usr/bin/node # ejecutable $ which python3 /usr/bin/python3 # ruta exacta del ejecutable

El PATH — cómo la shell encuentra los comandos

El PATH es una variable de entorno que contiene una lista de directorios donde la shell busca ejecutables. Cuando escribes node, la shell busca en cada carpeta del PATH hasta encontrarlo.

el PATH
# Ver el PATH actual $ echo $PATH /usr/local/sbin:/usr/local/bin:/usr/bin:/bin:/usr/games # Agregar una carpeta al PATH temporalmente $ export PATH="$PATH:/mi-carpeta/bin" # Para hacerlo permanente, agrégalo en ~/.bashrc $ echo 'export PATH="$PATH:/mi-carpeta/bin"' >> ~/.bashrc $ source ~/.bashrc # recarga la configuración sin reiniciar

Los Alias — Tus propios comandos cortos
1:08:59 — Crea atajos para los comandos que más usas

Un alias es un nombre corto que defines tú para reemplazar un comando largo. La shell lo sustituye automáticamente antes de ejecutar. Son una de las formas más simples de mejorar tu productividad en la terminal.

crear y usar alias
# Crear un alias temporal (dura hasta que cierras la terminal) $ alias ll='ls -la' $ alias gs='git status' $ alias ..='cd ..' $ alias cls='clear' # Ahora los puedes usar $ ll # ejecuta ls -la drwxr-xr-x 5 hugo hugo 4096 jun 15 10:30 . -rw-r--r-- 1 hugo hugo 220 jun 1 12:00 .bashrc # Ver todos los alias activos $ alias alias ll='ls -la' alias gs='git status' alias ..='cd ..' # Ver qué hace un alias específico $ alias ll alias ll='ls -la' # Eliminar un alias $ unalias ll

Hacer los alias permanentes — el archivo .bashrc

Los alias creados en la terminal desaparecen al cerrarla. Para que persistan entre sesiones debes guardarlos en el archivo de configuración de tu shell: ~/.bashrc (bash) o ~/.zshrc (zsh).

editar ~/.bashrc para alias permanentes
# Abre el archivo de configuración con nano $ nano ~/.bashrc # Al final del archivo, agrega tu sección de alias: # --- Mis alias personales --- alias ll='ls -la' alias la='ls -a' alias ..='cd ..' alias ...='cd ../..' alias cls='clear' alias gs='git status' alias ga='git add .' alias gc='git commit -m' alias gp='git push' alias py='python3' alias update='sudo apt update && sudo apt upgrade -y' # Guarda con Ctrl+O, Enter, Ctrl+X # Recarga la configuración SIN cerrar la terminal $ source ~/.bashrc # Verifica que funcionan $ ll

Alias útiles para desarrollo web

alias serve='python3 -m http.server'
Levanta un servidor HTTP local en la carpeta actual
$ serve 3000 → localhost:3000
alias myip='curl ifconfig.me'
Muestra tu IP pública desde la terminal
$ myip → 201.x.x.x
alias ports='ss -tuln'
Lista todos los puertos abiertos en el sistema
$ ports
alias reload='source ~/.bashrc'
Recarga la configuración de bash rápidamente
$ reload

🟢 Reglas para buenos alias

  • Nombres cortos (2–4 caracteres) y fáciles de recordar
  • No sobreescribas comandos existentes (no hagas alias ls='rm')
  • Agrúpalos por tema en tu .bashrc con comentarios
  • Comparte tu .bashrc en GitHub — así lo tienes en cualquier máquina

    • alias cls='clear'
    • alias gs='git status'
  9. Recarga con source ~/.bashrc y prueba que ll funcione.

🟢 Resumen de la Parte B

  • cat archivo — muestra contenido. cat -n con números. > sobreescribe, >> agrega.
  • less archivo — lectura paginada. q=salir, /=buscar, G=final, g=inicio, F=seguir en vivo.
  • head -n N / tail -n N — primeras/últimas N líneas. tail -f sigue el archivo en tiempo real.
  • nano: editor simple. ^O guardar, ^X salir, ^W buscar. Los atajos se muestran en pantalla.
  • vi/vim: 3 modos — Normal (Esc), Insert (i/a/o), Command (:). Guardar: :w. Salir: :q. Ambos: :wq. Forzar: :q!
  • 4 tipos de comandos: ejecutables, builtins, funciones y alias. Usa type para saber cuál es cuál.
  • El PATH es donde la shell busca ejecutables. Agrégale rutas en ~/.bashrc.
  • alias nombre='comando' — crea atajo temporal. Guarda en ~/.bashrc para permanente.
  • source ~/.bashrc — recarga la configuración sin cerrar la terminal.
