Un quiz con puntaje, preguntas barajadas, temporizador y récord guardado

Este es el resultado final. Juégalo: responde, mira cómo se pintan las respuestas, deja que se acabe el tiempo en alguna y llega hasta el resultado final:

En 7 pasos lo construyes entendiendo cada línea. Si hiciste la lista de tareas y la calculadora, ya conoces la base; aquí agregas arreglos de objetos, aleatoriedad y temporizadores (setInterval).

☕ Analogía

Un quiz es un programa de concurso: tiene un fichero de preguntas (los datos), un conductor que las va pasando (la lógica), un marcador (el estado) y un reloj de arena (el temporizador). Si separas bien estas piezas, cambiar las preguntas no obliga a tocar al conductor.

El punto de partida: HTML y CSS
Ya está hecho; el trabajo es el JavaScript

El HTML solo tiene espacios vacíos con id: el contador (info), el reloj, la barra, la pregunta, las opciones, el mensaje, el botón y el resultado. JavaScript los irá llenando. Fíjate también en los botones con el atributo hidden: empiezan escondidos.
