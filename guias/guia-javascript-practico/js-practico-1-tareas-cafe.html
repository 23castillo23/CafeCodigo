Lo que vas a construir
Una lista de tareas que se puede usar de verdad y recuerda lo que guardaste

Este es el resultado final. Pruébalo ahora: agrega tareas, tacha las que hiciste con un clic en el texto y bórralas con la ✕:

En 8 pasos vas a construir todo esto desde cero, entendiendo cada línea. Cada paso agrega una pieza y trae una vista previa en vivo: puedes editar el código y volver a ejecutarlo.

☕ Analogía

Es como armar un mueble por etapas: primero el esqueleto, luego las patas, después las puertas. Si ves el mueble terminado sin saber cómo se armó, parece magia; paso a paso, cada pieza tiene sentido.

Antes de empezar necesitas conocer lo básico de HTML, CSS y las variables y funciones de JavaScript. Para ver los mensajes de console.log en tu navegador real, abre las herramientas con F12; aquí aparecen en la consola negra bajo cada vista previa.
