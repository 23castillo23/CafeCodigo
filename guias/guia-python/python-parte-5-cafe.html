Listas
Muchos datos en una sola variable

Hasta ahora cada variable guardaba un dato. Una lista guarda varios, en orden, entre corchetes y separados por comas:

☕ Analogía

Una lista es una lista de compras, o un tren de vagones numerados: cada vagón (elemento) tiene su número de posición, empezando en el 0, y puedes cambiar lo que hay dentro de cualquiera.

  • frutas[0]: el primero. frutas[-1]: el último (igual que con los textos).
  • len(frutas): cuántos elementos hay.
  • frutas[1] = "mango": las listas se pueden modificar (los textos no).
  • frutas[0:2]: un trozo (del 0 hasta antes del 2).
Una lista puede mezclar tipos (["Ana", 20, True]) e incluso contener otras listas. Una lista vacía se escribe [] y es el punto de partida para ir agregando cosas.

Tuplas y conjuntos
Colecciones especiales

Una tupla es como una lista, pero no se puede modificar una vez creada. Se escribe con paréntesis:

La segunda línea es el desempaquetado: reparte cada valor de la tupla en una variable. ¿Qué pasa si intentas cambiarla?

☕ Analogía

Una lista es una pizarra (borras y escribes lo que quieras). Una tupla es una foto impresa: sirve para ver los datos, pero no se puede cambiar. Se usa para cosas que no deben cambiar, como coordenadas, fechas o colores RGB.

Conjuntos (set): sin repetidos

Un set se escribe con llaves, elimina duplicados y no tiene posiciones (no hay unicos[0]). Útil para saber "cuáles valores distintos hay".

📖
Diccionarios
Datos con nombre: clave → valor

En una lista los datos se buscan por posición. En un diccionario se buscan por un nombre (la clave). Se escribe con llaves, y cada pareja es clave: valor:

☕ Analogía

Un diccionario es un diccionario de verdad (buscas la palabra y te da su definición) o una agenda de contactos (buscas el nombre y te da el teléfono). No importa en qué posición esté: se busca por su nombre.

Agregar, cambiar y borrar

Recorrer un diccionario

  • .items(): pares (clave, valor) para usar en un for.
  • .keys(): solo las claves. .values(): solo los valores.
  • .get(clave, valor_por_defecto): busca sin que truene si no existe.

Si pides una clave que no existe con corchetes, Python lanza un KeyError:

Las claves son únicas: si asignas dos veces la misma clave, la segunda reemplaza a la primera.
