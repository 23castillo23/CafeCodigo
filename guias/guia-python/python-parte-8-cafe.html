¿Qué es la programación orientada a objetos?
Clases y objetos: moldes y piezas

Hasta ahora tenías datos por un lado (variables, listas) y funciones por otro. La programación orientada a objetos (POO) los junta: un objeto guarda sus datos y las acciones que puede hacer. Ya los usas: una lista es un objeto con datos (sus elementos) y acciones (.append(), .sort()...).

☕ Analogía

Una clase es un molde de galletas y cada objeto es una galleta hecha con ese molde. Todas tienen la misma forma, pero cada una puede tener su propio sabor y color. También: la clase es el plano de una casa y los objetos son las casas construidas con él.

Las piezas de una clase
Vocabulario esencial
class Perro:Crea la clase (el molde). Por convención, su nombre empieza con Mayúscula.
__init__El constructor: se ejecuta solo al crear un objeto. Ahí le das sus datos iniciales. (Dos guiones bajos a cada lado.)
self"Yo mismo": el propio objeto. Siempre es el primer parámetro de cada método.
self.nombreUn atributo: un dato que pertenece al objeto.
def ladrar(self)Un método: una función que pertenece a la clase.
Perro("Luna", 5)Crear un objeto (instancia): llamas a la clase como si fuera una función.

☕ Analogía

self es el objeto hablando de sí mismo: "mi nombre es...", "mi edad es...". Cuando Luna llama a ladrar(), self es Luna y dice su propio nombre; cuando lo hace Firulais, self es Firulais.

Al llamar a un método no escribes self: mi_perro.ladrar(). Python lo pasa solo (el objeto que está antes del punto). Pero al definir el método sí debes ponerlo.

Mostrar un objeto con __str__
Para que print() sea legible

Si haces print(objeto) sin más, Python muestra algo poco amigable (el tipo y una dirección de memoria). Con el método especial __str__ decides cómo se ve tu objeto como texto:

Observa que __str__ usa return (devuelve el texto) y no print. Python lo llama automáticamente cuando necesita convertir el objeto a texto, ya sea en print o dentro de una f-string.

Los métodos con dos guiones bajos a cada lado (__init__, __str__) se llaman métodos especiales: Python los llama por su cuenta en momentos concretos. Hay muchos más (por ejemplo, para comparar o sumar objetos), pero estos dos son los que usarás todos los días.

Proyecto final: Agenda de contactos
Todo lo que aprendiste, en un solo programa

Este programa junta todas las partes del curso. Léelo con calma y busca cada concepto:

  • Parte 2-3: textos, f-strings, input, if/elif/else.
  • Parte 4: while True con break (el menú) y for.
  • Parte 5: una lista de objetos (la agenda), enumerate, diccionarios.
  • Parte 6: funciones con parámetros y return.
  • Parte 7: try/except, archivos y JSON.
  • Parte 8: la clase Contacto con __init__ y __str__.

Ejecútalo: te irá pidiendo datos con ventanitas (opciones del 1 al 5). Agrega contactos, véelos, búscalos, guarda y sal. Después ejecútalo otra vez sin cerrar la página: gracias a cargar(), ¡recuerda los contactos que guardaste!

☕ Analogía

Mira cómo está organizado: una clase para el dato (Contacto) y una función por tarea (agregar, ver, buscar, guardar, cargar). El menu() solo coordina. Es como un restaurante: el mesero (menú) no cocina; pasa el pedido a la cocina correcta.

Retos para mejorarlo (hazlos tú)

  1. Eliminar un contacto por nombre (opción 6).
  2. Validar que el teléfono tenga solo números y guiones, con un while + try/except o if.
  3. Mostrar la agenda ordenada alfabéticamente.
  4. Guardar automáticamente al elegir "Salir".
  5. Agregar un campo correo a la clase Contacto.
Consejo para practicar: copia este código a un archivo agenda.py en tu computadora y ejecútalo con python agenda.py. Ahí el archivo agenda.json se guarda de verdad en tu carpeta.
