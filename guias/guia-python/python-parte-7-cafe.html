Excepciones: try / except
Que tu programa no se caiga cuando algo falla

Cuando Python encuentra un error en plena ejecución, lanza una excepción y el programa se detiene. Ya viste muchas: ValueError, ZeroDivisionError, KeyError... Con try / except puedes atraparlas y decidir qué hacer en vez de caerte:

try:"Intenta esto". Aquí va el código que podría fallar.
except ValueError:"Si falla con este tipo de error, haz esto otro". Solo corre si hubo excepción de ese tipo.
DespuésEl programa continúa normal, sin traceback ni cierre inesperado.

☕ Analogía

Es la red de seguridad de un trapecista: si todo sale bien, nunca se usa. Si se cae (hay una excepción), la red lo atrapa y puede seguir con el show en vez de terminar en el suelo.

Cuando hay una excepción, el resto del bloque try se salta. En el ejemplo, el print(numero) nunca se ejecutó porque int("hola") ya había fallado.
🎛️
except, else y finally
Más control sobre el manejo de errores

Puedes atrapar distintos errores con respuestas distintas, usar else (corre si no hubo error) y finally (corre siempre):

  • Cada llamada imprime (división intentada): finally se ejecuta siempre, haya error o no (incluso si hay un return). Sirve para "limpiar": cerrar cosas, avisar que terminó.
  • else es el camino feliz: solo corre si el try salió sin excepciones.

Ver el mensaje del error: as e

except Exception as e atrapa cualquier error común y guarda el objeto del error en e, para mostrar su mensaje o su tipo.

ExcepciónCuándo ocurre
ValueErrorValor correcto en tipo pero inválido: int("abc")
TypeErrorTipo equivocado: "a" + 1
ZeroDivisionErrorDividir entre cero
IndexErrorPosición de lista inexistente
KeyErrorClave de diccionario inexistente
FileNotFoundErrorEl archivo no existe
NameErrorVariable que no existe
Buena práctica: atrapa el error más específico que esperas (ValueError) en vez de uno genérico. Y nunca escribas un except que ignore todo en silencio: ocultarías errores reales y sería muy difícil encontrarlos después.

Leer y escribir archivos
Guardar información más allá del programa

Hasta ahora, todo lo que tu programa guardaba en variables desaparece al terminar. Los archivos permiten guardar datos de forma permanente. Se abren con open(nombre, modo):

ModoSignificaCuidado
"r"Leer (read). Es el modo por defectoEl archivo debe existir o hay FileNotFoundError
"w"Escribir (write)Borra todo lo que había y empieza de cero
"a"Agregar al final (append)Conserva lo anterior

☕ Analogía

Un archivo es un cuaderno. "r" es abrirlo solo para leer. "w" es sacar un cuaderno nuevo (¡tirando el anterior!). "a" es abrir tu cuaderno donde ibas y seguir escribiendo en la siguiente hoja.

En esta guía los archivos viven dentro de la memoria de la página y desaparecen al recargar. En tu computadora, el mismo código crea archivos reales en la carpeta de tu programa.

Escribir y leer

with abre el archivo y lo cierra automáticamente al terminar el bloque, incluso si hay errores. Es la forma recomendada. El \n es un salto de línea: write no lo agrega solo.

☕ Analogía

with es como pedir un libro prestado en la biblioteca con devolución automática: lo usas dentro del bloque y, al salir, se devuelve solo. Sin with tendrías que acordarte de cerrarlo tú.

Leer línea por línea

Un archivo se puede recorrer con for: cada vuelta trae una línea. .strip() quita el salto de línea sobrante del final de cada una.

Módulos y JSON
Usar código que ya escribieron otros

Python trae decenas de módulos listos para usar. Se cargan con import:

  • import math y luego math.sqrt(...): usas el nombre del módulo como prefijo.
  • from math import factorial: traes solo lo que necesitas y lo usas directo.

☕ Analogía

Importar un módulo es como pedir prestada una caja de herramientas a un vecino: no tienes que fabricar tu propio martillo. math trae las herramientas de matemáticas; random, las de azar; json, las de guardar datos.

random: azar (¡para mejorar el juego de la Parte 4!)

Sin seed, cada ejecución da resultados distintos. Para el juego de adivinar usarías secreto = random.randint(1, 10), y cada partida sería diferente.

json: guardar datos estructurados

JSON es un formato de texto para guardar diccionarios y listas (lo usan casi todas las aplicaciones y APIs). Convertir entre Python y JSON:

  • json.dumps(datos): de Python a texto JSON (dump string).
  • json.loads(texto): de texto JSON a Python (load string).
  • Con archivos existen json.dump(datos, archivo) y json.load(archivo).
