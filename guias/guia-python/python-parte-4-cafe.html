¿Por qué repetir?
El poder de que la computadora haga lo aburrido

Imagina que quieres escribir "Hola" cinco veces. Podrías copiar y pegar la línea, pero ¿y si fueran 1000? Para eso existen los bucles (o ciclos): instrucciones que repiten un bloque de código mientras se cumpla algo o una cantidad de veces.

☕ Analogía

Un bucle es como las vueltas a una pista de carreras: el corredor repite el mismo recorrido varias veces. Lo importante es saber cuándo se detiene: después de 5 vueltas (for) o cuando se acabe la gasolina (while).

Python tiene dos tipos de bucles: while ("mientras") y for ("para cada"). Vamos con el primero.

🔄
while: repetir mientras se cumpla
La condición decide cuándo parar

while funciona como un if que se repite: revisa la condición y, mientras sea True, ejecuta el bloque una y otra vez. Cuando se vuelve False, el bucle termina y el programa sigue.

☕ Analogía

"Mientras tengas hambre, sigue comiendo." Cada bocado cambia algo (tienes menos hambre) y en algún momento la condición deja de cumplirse y paras de comer.

Las 3 partes de un while bien hecho

1. Iniciocontador = 1: la variable que controla el bucle empieza en algún valor.
2. Condiciónwhile contador <= 5:: se revisa antes de cada vuelta. Si es False, se acabó.
3. Cambiocontador += 1: dentro del bloque algo debe cambiar para que la condición algún día sea False.

⚠️ El bucle infinito

Si olvidas la parte 3, la condición nunca cambia y el bucle no termina jamás. Este código es un ejemplo (no lo copies sin cuidado):

contador = 1
while contador <= 5:
    print("Vuelta", contador)
    # ¡Falta contador += 1!  → se repite para siempre
Si te pasa: en la terminal, detén el programa con Ctrl + C. En esta guía, Python se detiene solo después de un rato y te avisa. Un bucle infinito no daña nada: es un error común y se arregla agregando el cambio que falta.

Acumuladores: ir sumando

total es un acumulador: empieza en 0 y en cada vuelta se le agrega algo. Es un patrón que usarás constantemente.

for y range()
Repetir un número exacto de veces o recorrer algo

for significa "para cada". Recorre una serie de valores y en cada vuelta guarda el valor actual en una variable. La serie de números más común se crea con range():

Dos cosas importantes: empieza en 0 y el 5 no se incluye (da 0, 1, 2, 3, 4: cinco números). Igual que con las posiciones de un texto.

EscribesGeneraSe lee
range(5)0, 1, 2, 3, 4de 0 hasta antes de 5
range(1, 6)1, 2, 3, 4, 5de 1 hasta antes de 6
range(0, 10, 2)0, 2, 4, 6, 8de 2 en 2
range(5, 0, -1)5, 4, 3, 2, 1cuenta regresiva (paso negativo)

☕ Analogía

for es como pasar lista en el salón: el maestro llama a cada alumno, uno por uno, y con cada nombre hace lo mismo ("presente"). La variable (i) es el nombre del alumno al que le toca en ese momento.

Recorrer un texto

El for no solo recorre números: recorre cada elemento de lo que le des (aquí, cada letra). En la Parte 5 lo usarás con listas.

break y continue
Controlar el bucle desde adentro

break sale del bucle inmediatamente. continue salta el resto de esta vuelta y pasa a la siguiente.

☕ Analogía

break es el botón de salida de emergencia: en cuanto lo aprietas, te vas de la atracción sin terminar las vueltas.

☕ Analogía

continue es saltar una canción en la lista de reproducción: esa no suena, pero la lista sigue con la siguiente. Aquí, los pares se saltan y solo se imprimen los impares.

Ambos casi siempre van dentro de un if: "si pasa tal cosa, salgo (break) o me salto esta vuelta (continue)".
