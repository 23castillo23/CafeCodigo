¿Qué es una función?
Tu propio comando reutilizable

Ya usaste muchas funciones: print(), len(), input(), range()... Son bloques de código con nombre que hacen una tarea. Ahora aprenderás a crear las tuyas.

☕ Analogía

Una función es una máquina de café: le das ingredientes (los parámetros), presionas el botón (llamas a la función) y te entrega una bebida (el resultado). No necesitas saber cómo funciona por dentro cada vez que quieres un café: solo la usas.

Crear y llamar una función
def y los paréntesis

Se crea con def (de define), un nombre, paréntesis y dos puntos. El bloque con sangría es lo que hace la función. Para usarla la llamas por su nombre con paréntesis:

def saludar():def + nombre + () + : como un if, el bloque lleva sangría.
saludar()La llamada: aquí es donde de verdad se ejecuta. Cada llamada ejecuta todo el bloque otra vez.

☕ Analogía

Definir una función es escribir la receta en tu libro de cocina: no se cocina nada todavía. Llamarla es cocinar la receta. Puedes tener cien recetas escritas y no cocinar ninguna.

Definir no ejecuta. Si solo escribes el def y nunca llamas a la función, el programa no muestra nada. Y la llamada siempre lleva paréntesis: saludar sin () no la ejecuta.
Nombres: mismas reglas que las variables (minúsculas con guion bajo) y que digan qué hace la función: calcular_total, es_par, mostrar_menu.

return: devolver un resultado
Que la función entregue algo

Hasta ahora las funciones solo mostraban cosas. Con return devuelven un valor que puedes guardar en una variable o usar en otra operación:

print no es return

Es la confusión más común. Compara:

con_print mostró 10 pero no entregó nada: por eso a vale None ("nada"). con_return entregó el 10 y b lo guardó.

☕ Analogía

print es decir el resultado en voz alta: lo oyes, pero se lo lleva el aire y no puedes usarlo después. return es poner el resultado en tu mano: ahora puedes guardarlo, sumarlo o pasárselo a otra función.

return termina la función

Al ejecutarse un return la función termina de inmediato. (Esta función también se podría escribir en una línea: return edad >= 18.)

Devolver varios valores

Separar valores con comas en el return los entrega como una tupla, y el desempaquetado (Parte 5) los reparte en dos variables.

🎚️
Valores por defecto y nombres
Parámetros opcionales

Puedes darle a un parámetro un valor por defecto con =. Si al llamar no mandas ese argumento, se usa el de defecto:

  • Primera llamada: usa el "Hola" por defecto.
  • Segunda: reemplazas el saludo con tu propio valor.
  • Tercera: argumentos con nombre (saludo=...): puedes darlos en cualquier orden porque cada uno dice a cuál parámetro pertenece.

☕ Analogía

Es pedir café en una cafetería: "un americano" sale con el tamaño mediano por defecto. Si quieres, puedes especificar "grande"; si no dices nada, te dan el estándar.

Los parámetros con valor por defecto van siempre al final. def f(a=1, b) da error.

Cada función es un cuarto cerrado: lo que haces adentro (tus variables) no se ve desde fuera. Se comunica con el mundo por dos puertas: la entrada (parámetros) y la salida (return). Eso mantiene el orden y evita que unas funciones pisen las variables de otras.

Modificar una variable global (con cuidado)

Sin la palabra global, Python daría error. Aunque funciona, casi siempre es mejor que la función reciba el valor como parámetro y devuelva el nuevo con return: el código es más fácil de entender y de probar.
