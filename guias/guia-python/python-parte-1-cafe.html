¿Qué es Python?
Tu primer vistazo, sin miedo

Python es un lenguaje de programación: una forma de escribir instrucciones que una computadora entiende. Con él se crean páginas web, programas de escritorio, juegos, análisis de datos, automatización de tareas y hasta inteligencia artificial.

☕ Analogía

Programar es como escribir una receta de cocina. La receta (tu programa) tiene pasos en orden, y la computadora es un cocinero muy obediente pero que no adivina nada: hace exactamente lo que dice la receta, ni más ni menos. Python es el idioma en el que escribes esa receta.

¿Por qué Python para empezar? Porque se lee casi como inglés, tiene pocas reglas raras y es de los lenguajes más usados del mundo. Mira lo que hace con solo 3 líneas. Presiona ▶ Ejecutar:

Cómo funciona esta guía: todos los cuadros oscuros con el botón ▶ son ejecutables y editables. Cambia el código, vuelve a ejecutar y mira qué pasa: romper cosas es la mejor forma de aprender. La primera vez Python tarda unos segundos en cargar (necesita internet); después es instantáneo.

Instalar y ejecutar Python
Para cuando quieras practicar en tu computadora

Para esta guía no necesitas instalar nada: los ejemplos corren en tu navegador. Pero para hacer tus propios programas, conviene tener Python en tu computadora:

  1. Descarga Python de python.org/downloads (botón amarillo).
  2. En Windows, al instalar marca la casilla "Add Python to PATH". Es el paso que más se olvida y sin él la terminal no encuentra Python.
  3. Abre una terminal y comprueba la instalación:
python --version
# En Windows también funciona:  py --version

Debe responder algo como Python 3.12.4 (el número exacto puede variar). Si sale un error, revisa el paso del PATH.

El modo interactivo es una conversación: preguntas algo y te responde al instante. El modo archivo es una carta larga: escribes todo el programa y se lo entregas completo para que lo lea de arriba hacia abajo.

Editor recomendado: VS Code con la extensión Python de Microsoft. Crea un archivo que termine en .py y ejecútalo con el botón ▶ de arriba a la derecha o con python nombre.py.

  • \n dentro de un texto es un salto de línea.

Comentarios
Notas que Python ignora

Un comentario empieza con #. Python ignora todo lo que va después en esa línea. Sirven para explicarte (o explicarle a otros) qué hace el código.

☕ Analogía

Los comentarios son notas al margen de un libro o post-its pegados en la receta: no cambian el platillo, pero te recuerdan por qué hiciste cada cosa.

Truco: para "apagar" una línea sin borrarla, ponle # al inicio (en VS Code: Ctrl + /). Los programadores lo hacen todo el tiempo al probar cosas.

Variables
Guardar datos para usarlos después

Una variable es un nombre que guarda un valor. Se crea con el signo =:

☕ Analogía

Una variable es una caja con etiqueta. La etiqueta (nombre) es cómo la llamas y adentro va el valor ("Ana"). Cuando escribes print(nombre), Python busca la caja con esa etiqueta y muestra lo que tiene adentro.

Ojo: en programación = no significa "es igual a" como en matemáticas. Significa "guarda lo de la derecha en lo de la izquierda". Se lee: "edad recibe 20".

Las variables pueden cambiar

La caja se queda con el último valor que le guardaste. La tercera línea de cambio, edad = edad + 1, dice: "toma lo que hay en edad, súmale 1 y guárdalo otra vez en edad".
