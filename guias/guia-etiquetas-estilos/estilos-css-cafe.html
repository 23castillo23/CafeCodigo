🎨 Guía de estilos CSS

El HTML pone las piezas (<p>, <h1>, <button>…) y el CSS decide cómo se ven. Una regla siempre tiene esta forma: selector { propiedad: valor; }. En cada tarjeta puedes editar el CSS y ver el resultado al instante.

☕ Analogía

Como poner los libros en un estante alto: pegados arriba, al centro o abajo.

Reto Pruébalo tú

Prueba center y flex-end.

CSS.fila { display: flex; align-items: center; }
21flex-directionse ve en <div>
Edita el CSS y mira el cambio en vivo

Qué hace: cambia si los hijos van en fila (row) o en columna (column).

☕ Analogía

☕ Analogía

Como el dedo de un guía turístico: una manita te dice "aquí sí puedes hacer clic".

Ponle cursor: pointer y pasa el mouse.

24transitionse ve en <button>
Edita el CSS y mira el cambio en vivo
