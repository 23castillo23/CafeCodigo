🌱 Nivel 5 — Instalar Linux
🗺️
¿Cómo quieres instalar Linux?
Tres caminos distintos según tu situación y nivel de compromiso

No hay una sola forma de instalar Linux. Antes de empezar, elige el camino que mejor se adapta a tu situación. Cada uno tiene ventajas y limitaciones concretas.

🖥️
Máquina virtual (VM)
Linux corre dentro de una ventana en tu sistema actual. No tocas tu disco real. Perfecto para experimentar sin riesgo. Requiere al menos 8 GB de RAM.
✓ Recomendado para empezar
🪟
Dual boot
Linux y Windows conviven en el mismo disco en particiones separadas. Al encender eliges cuál arrancar. Rendimiento nativo, pero hay que particionar con cuidado.
⚡ Rendimiento real
🐧
Instalación única
Linux ocupa todo el disco. La forma más limpia y simple. Ideal si tienes una computadora extra o ya decidiste pasarte a Linux completamente.
✓ Más simple
🪟
WSL2 (Windows)
Windows Subsystem for Linux — terminal Linux integrada en Windows 11/10. No es un Linux completo pero sirve para aprender la terminal sin instalar nada.
⚡ Sin instalar

🟢 Recomendación para esta guía

Si es tu primera vez: empieza con una máquina virtual con VirtualBox o VMware usando Ubuntu 24.04 LTS. Es gratis, sin riesgo, y puedes experimentar todo lo que quieras sin miedo a romper nada. Cuando te sientas cómodo, da el salto al dual boot o instalación completa.

✅
Checklist antes de instalar
Lo que debes verificar antes de arrancar el instalador

Instalar Linux en hardware real requiere preparación. Omitir alguno de estos pasos es la causa del 90% de los problemas que reportan los principiantes.

💾
Haz un backup de tus datos Copia tus archivos importantes a un disco externo o la nube. Si algo sale mal durante la instalación, tu disco puede quedar en un estado inconsistente.
🔋
Enchufa el cargador (laptops) Una instalación que se interrumpe por batería baja puede dejar el sistema en estado de arranque roto. Siempre instala con el cargador conectado.
📶
Conecta a internet (si puedes) El instalador descarga actualizaciones y drivers adicionales durante la instalación. Con cable ethernet es más fiable que WiFi durante este proceso.
💿
USB de al menos 8 GB El ISO de Ubuntu 24.04 LTS pesa ~5.5 GB. Necesitas un USB de 8 GB mínimo. Todo lo que haya en el USB se borrará al crear el booteable.
🔑
Desactiva Secure Boot (si necesario) Ubuntu moderno soporta Secure Boot. Pero si tienes problemas al arrancar el USB, desactivarlo en la UEFI suele resolverlo. Puedes reactivarlo después.
🗂️
Anota el espacio disponible en disco Linux necesita mínimo 25 GB para instalarse con comodidad. 50 GB es lo recomendado para uso normal. 100 GB+ si vas a programar y guardar proyectos.

⚠️ El error más común

Instalar Linux sin hacer backup y sin leer el particionador con calma. El instalador muestra claramente qué va a hacer con tu disco — léelo dos veces antes de hacer clic en "Instalar". Una vez que el instalador formatea, no hay vuelta atrás.

💿
Crear un USB booteable
Descargar el ISO y grabarlo correctamente en el USB

Un USB booteable contiene el instalador de Linux grabado de forma especial para que la computadora pueda arrancar desde él. No es simplemente copiar el archivo ISO — hay que "quemar" el ISO con una herramienta específica.

📼 Analogía — No es copiar, es grabar

Copiar el archivo ISO al USB es como intentar instalar Windows copiando el DVD a una carpeta — no funciona. El ISO tiene que grabarse en el USB de forma que la UEFI pueda leerlo como disco de arranque. Es como la diferencia entre copiar música a un casete y grabarla correctamente con la velocidad y el formato adecuados.

1
Descarga el ISO de Ubuntu 24.04 LTS
Entra a ubuntu.com/download/desktop y descarga el archivo .iso (~5.5 GB). Verifica el checksum SHA256 para asegurarte de que la descarga está íntegra.
2
Descarga Balena Etcher o Rufus
Balena Etcher (Windows/Mac/Linux) es el más simple: solo arrastrar el ISO, seleccionar el USB y clic en Flash. Rufus (solo Windows) da más opciones. Cualquiera de los dos funciona perfectamente.
3
Graba el ISO en el USB
Abre Etcher → selecciona el ISO → selecciona el USB → clic en Flash. El proceso tarda 5–10 minutos. Todo el contenido del USB se borrará — guarda lo que necesites antes.
4
Arranca desde el USB
Inserta el USB, reinicia la computadora y entra al boot menu presionando F12, F11, Esc o Del (varía por fabricante). Selecciona el USB en el menú y Ubuntu arrancará en modo live.

💡 Modo Live — prueba sin instalar

Al arrancar desde el USB, Ubuntu te ofrece "Probar Ubuntu" antes de instalar. Úsalo. El modo live carga Ubuntu completamente en la RAM — puedes navegar, usar aplicaciones y comprobar que el WiFi, audio y pantalla funcionan en tu hardware antes de comprometerte con la instalación.

UEFI vs BIOS — el firmware de arranque
El programa que arranca antes que cualquier sistema operativo

Antes de que Linux arranque, el firmware de la placa base toma el control. Existen dos tipos: el antiguo BIOS y el moderno UEFI. Saber cuál tienes afecta cómo configuras el arranque y las particiones.

Interfaz de texto, teclado solo
Solo discos MBR (máx 2 TB)
Máximo 4 particiones primarias

Computadoras pre-2012
⚡ UEFI (Moderno)
Interfaz gráfica con ratón
Discos GPT (hasta 9.4 ZB)
Particiones ilimitadas
Secure Boot disponible
Arranque más rápido
Computadoras post-2012
# Cómo saber si tienes UEFI o BIOS (en Windows): Método 1: Win + R → msinfo32 → busca "Modo BIOS" Si dice UEFI → tienes UEFI Si dice Legado → tienes BIOS Legacy Método 2: Si existe la carpeta C:\Windows\Boot\EFI → UEFI Si existe C:\Windows\Boot\PCAT → BIOS Legacy # En Linux (si ya lo tienes instalado): $ ls /sys/firmware/efi → Si existe la carpeta, es UEFI

📌 Secure Boot y Linux

Secure Boot es una función UEFI que verifica que solo software firmado digitalmente pueda arrancar. Ubuntu y Fedora incluyen sus propias firmas y funcionan con Secure Boot activado. Si usas otra distro o tienes problemas, desactívalo en la configuración UEFI. No es un riesgo de seguridad desactivarlo en una computadora personal.

Particiones de disco
Cómo dividir el espacio del disco para Linux

Una partición es una división lógica del disco duro — como separar un cajón grande en compartimentos más pequeños. Linux necesita al menos una partición para instalarse, pero lo habitual es tener varias con propósitos distintos.

🏠 Analogía — Dividir un apartamento

Tu disco es el apartamento. Las particiones son las habitaciones: sala, cocina, dormitorio, baño. Puedes vivir en un estudio sin divisiones (una sola partición), pero tener habitaciones separadas te da orden: si inundas la cocina (llenas la partición /home), el dormitorio (el sistema en /) no se ve afectado.

🟢 Consejo para principiantes — dejar que el instalador decida

Ubuntu y Linux Mint tienen la opción "Instalar junto a Windows" o "Borrar disco e instalar". Si eliges una de estas, el instalador crea las particiones automáticamente de forma óptima. El particionado manual es para cuando ya sabes lo que haces. Para tu primera instalación: deja que el instalador decida.

💡 ¿Por qué separar / y /home?

Si / y /home están en la misma partición y el sistema se llena, pueden ocurrir errores del SO. Más importante: si algún día reinstalaas Linux, puedes formatear solo / (el sistema) y mantener /home intacto con todos tus archivos. Es como renovar la casa sin tocar el contenido.

🪟
Dual Boot — Linux y Windows juntos
Convivencia pacífica de dos sistemas en el mismo disco

Con dual boot instalas Linux junto a Windows en el mismo disco. Al encender la computadora, GRUB te muestra un menú para elegir cuál sistema arrancar. Obtienes lo mejor de los dos mundos sin sacrificar ninguno.

🏠 Analogía — Dos apartamentos en el mismo edificio

El dual boot es como vivir en un edificio con dos apartamentos: uno decorado como Windows (para el trabajo, juegos, Office) y otro como Linux (para programar, aprender, experimentar). El portero (GRUB) te pregunta al entrar a cuál quieres ir. Los apartamentos no se mezclan, pero comparten el edificio.

Pasos para configurar dual boot

1
Libera espacio en Windows
Abre el Administrador de discos en Windows (click derecho en inicio → Administración de discos). Haz click derecho en la partición C: → Reducir volumen. Libera al menos 50 GB para Linux. Windows creará espacio no asignado.
2
Desactiva Fast Startup en Windows
Panel de control → Opciones de energía → Elegir el comportamiento del botón de inicio/apagado → Desactiva "Inicio rápido". Este modo deja Windows en un estado "congelado" que puede corromper sus archivos si Linux los lee.
3
Arranca el instalador de Linux
Arranca desde el USB booteable. En el instalador elige "Instalar junto a Windows". El instalador detectará Windows automáticamente y usará el espacio no asignado que liberaste.
4
GRUB se instala automáticamente
El instalador instala GRUB como gestor de arranque. Desde ahora, al encender verás el menú de GRUB con opciones para Ubuntu y Windows. El timeout por defecto es 10 segundos, luego arranca Linux.

⚠️ Cuidado con las actualizaciones de Windows

Las actualizaciones grandes de Windows (Feature Updates) a veces sobreescriben el MBR/EFI y eliminan GRUB. Si tras actualizar Windows ya no aparece el menú de GRUB, no entres en pánico — Linux sigue ahí. Arranca desde el USB live y usa boot-repair para restaurar GRUB. Es un problema conocido y tiene solución.

🚀
La instalación paso a paso
Lo que verás en el instalador de Ubuntu 24.04 LTS

El instalador de Ubuntu es uno de los más amigables de todas las distros. Aquí el recorrido completo de lo que verás en pantalla.

1
🌐 Idioma y accesibilidad
Elige español. El instalador cambia todo el idioma al instante. También puedes activar opciones de accesibilidad si las necesitas.
2
⌨️ Distribución de teclado
Elige Spanish (Latin American) si tu teclado tiene ñ y acentos. Prueba escribir en el campo de texto que aparece para verificar que los caracteres especiales funcionan correctamente.
3
📶 Conexión a internet
Conecta a tu red WiFi o deja la conexión por cable. Si te conectas, el instalador descargará actualizaciones automáticamente. Si no tienes internet, puedes actualizarlo después.
4
📦 Tipo de instalación
Elige entre "Instalación predeterminada" (Firefox, LibreOffice incluidos) o "Instalación mínima" (solo lo esencial). Para empezar, la predeterminada es más cómoda.
5
💽 Tipo de instalación en disco
La pantalla más importante. Elige "Instalar junto a Windows" para dual boot, o "Borrar disco" para instalación única. Lee con calma antes de confirmar — esta acción no tiene deshacer.
6
🌍 Zona horaria
Haz clic en el mapa en tu región o escribe tu ciudad. El sistema usará esta zona para la hora del sistema.
7
👤 Usuario y contraseña
Escribe tu nombre, el nombre del equipo (hostname), tu nombre de usuario y una contraseña segura. Activa "Requerir contraseña para iniciar sesión". Este usuario tendrá permisos de sudo (administrador).
8
⏳ Instalación en progreso
El instalador copia los archivos, configura el bootloader y personaliza el sistema. Tarda entre 10 y 25 minutos según la velocidad del disco y la conexión a internet. Al terminar, reinicia y retira el USB.

Primeros pasos tras la instalación
Lo primero que debes hacer en tu nuevo sistema Linux

¡Tienes Linux instalado! Ahora hay un orden recomendado de primeras acciones para dejar el sistema actualizado, seguro y listo para trabajar.

✓
Actualizar todo el sistema
Lo primero siempre. Actualiza el índice de paquetes y todos los paquetes instalados a sus versiones más recientes.
✓
Instalar drivers adicionales
Ubuntu detecta automáticamente hardware que necesita drivers privativos (NVIDIA, WiFi broadcom, etc.) y los ofrece en "Software y actualizaciones → Controladores adicionales".
✓
Configurar el idioma completo
Configuración → Sistema → Región e idioma → instala el soporte de idioma completo si faltan paquetes. Esto asegura que fechas, monedas y formatos estén en español.
✓
Instalar tus herramientas básicas
VS Code, Git, Node.js, tu navegador preferido. Todo desde la terminal con apt o desde el Centro de Software.
comandos esenciales post-instalación en Ubuntu
# 1. Actualizar todo el sistema $ sudo apt update && sudo apt upgrade -y # 2. Instalar herramientas de desarrollo esenciales $ sudo apt install -y build-essential git curl wget # 3. Instalar VS Code $ sudo snap install code --classic # 4. Instalar Node.js (via nvm — la forma recomendada) $ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash $ nvm install --lts # 5. Ver info básica del sistema $ uname -r # versión del kernel $ lsb_release -a # info de la distro $ df -h # espacio en disco $ free -h # memoria RAM disponible

🟢 La regla de oro post-instalación

Ejecuta sudo apt update && sudo apt upgrade una vez a la semana. Mantener el sistema actualizado es la medida de seguridad más importante en Linux. Las actualizaciones incluyen parches de seguridad del kernel y de todas las aplicaciones instaladas.

✏️ Ejercicio del Nivel 5 Práctica real

Opción A — Máquina Virtual (recomendado para empezar):

  1. Descarga e instala VirtualBox (gratuito) desde virtualbox.org
  2. Descarga el ISO de Ubuntu 24.04 LTS desde ubuntu.com
  3. Crea una VM nueva: 4 GB RAM, 50 GB disco, 2 CPUs, activa "Enable EFI"
  4. Asigna el ISO como disco de arranque y arranca la VM
  5. Instala Ubuntu con las opciones por defecto y completa los primeros pasos
  6. Abre la terminal y ejecuta: sudo apt update && sudo apt upgrade -y

Opción B — Hardware real:

  1. Haz el backup de tus datos importantes
  2. Crea el USB booteable con Balena Etcher + ISO Ubuntu 24.04
  3. Instala en dual boot o instalación única según tu situación
  4. Completa los primeros pasos post-instalación de este nivel

Verificación: Al terminar debes poder abrir la terminal y ejecutar uname -r y ver la versión del kernel de Linux. ¡Eso significa que estás corriendo Linux!

🟥 Resumen del Nivel 5

  • Tienes 4 opciones: VM (sin riesgo), dual boot (con Windows), instalación única o WSL2.
  • Antes de instalar: backup, cargador conectado, USB de 8 GB+, 50 GB de espacio libre.
  • El USB booteable se crea con Balena Etcher o Rufus — no se copia el ISO, se graba.
  • UEFI es el firmware moderno (post-2012). Soporta discos GPT, Secure Boot y arranque rápido.
  • Linux necesita particiones: /boot/efi (512 MB), swap, / (sistema) y /home (tus archivos).
  • Para dual boot: libera espacio en Windows, desactiva Fast Startup, instala Linux en el espacio libre.
  • GRUB es el gestor de arranque que aparece al encender y te permite elegir SO.
  • Post-instalación: sudo apt update && sudo apt upgrade siempre primero.
