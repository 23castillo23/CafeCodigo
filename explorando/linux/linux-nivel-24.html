🧰 Nivel 24 — Herramientas de Terminal
🧰
¿Por qué instalar más herramientas de terminal?
Los comandos clásicos (ps, df, ls, find, grep) funcionan siempre — pero hay alternativas que ahorran tiempo

Linux trae de fábrica todo lo necesario para trabajar: ls, cat, find, grep, df, top... Esos comandos existen desde hace más de 40 años y no van a desaparecer. Pero alrededor de ellos ha crecido una generación de herramientas de terminal modernas: más rápidas, con colores, con información visual, escritas en Rust o Go, pensadas para que un humano las lea cómodamente en vez de solo procesarlas con scripts.

🔧 Analogía — La caja de herramientas del mecánico

Un mecánico puede aflojar cualquier tornillo con una llave inglesa universal. Funciona siempre, en cualquier coche. Pero si tiene el destornillador exacto, la llave de vaso del tamaño correcto o la pistola de impacto, el mismo trabajo le toma la mitad de tiempo y con menos esfuerzo. Los comandos clásicos (ps, df, find) son la llave universal: siempre están ahí. Las herramientas de este nivel son el resto de la caja: no imprescindibles, pero una vez las pruebas, no quieres volver atrás.

💡 No sustituyen, complementan

Ninguna herramienta de este nivel reemplaza a la que ya conoces de niveles anteriores. btop no reemplaza a top/htop, simplemente los mejora visualmente. Aprende primero el comando clásico (que estará en cualquier servidor al que te conectes por SSH) y usa estas herramientas modernas en tu propio equipo, donde sí puedes instalar lo que quieras.

📦
Instalación según tu distro
Linux Mint, Zorin OS y Voyager comparten gestor de paquetes — el resto varía

Linux Mint, Zorin OS y Voyager son las tres distros de las que hablas, y las tres están construidas sobre Ubuntu/Debian. Eso significa que las tres usan exactamente el mismo gestor de paquetes: apt. Todo lo que instales con sudo apt install en una, funciona igual en las otras dos.

🟢 Linux Mint → apt (base Ubuntu) 🟢 Zorin OS → apt (base Ubuntu) 🟢 Voyager → apt (base Debian)
Familia de distroGestorInstalarActualizar lista
Mint / Zorin / Voyager / Ubuntu / DebianAPTsudo apt install paquetesudo apt update
Fedora / NobaraDNFsudo dnf install paquetesudo dnf check-update
Arch / Manjaro / EndeavourOSPacmansudo pacman -S paquetesudo pacman -Sy
openSUSEZyppersudo zypper install paquetesudo zypper refresh

⚠️ No todo está en los repos oficiales de Mint/Zorin/Voyager

Como estas tres distros se basan en versiones de Ubuntu/Debian que priorizan la estabilidad sobre la novedad, algunos paquetes muy recientes (por ejemplo eza o versiones nuevas de fastfetch) pueden no estar en apt todavía o venir en una versión antigua. Para esos casos usarás snap, flatpak o el paquete .deb descargado directamente de GitHub — se indica en cada herramienta de abajo.

rutina antes de instalar cualquier cosa
# Siempre primero: refrescar la lista de paquetes disponibles $ sudo apt update # Buscar si un paquete existe en los repos antes de instalar a ciegas $ apt search fastfetch $ apt-cache policy btop # ver qué versión te daría apt # Snap y Flatpak — alternativas cuando apt no tiene el paquete o está desactualizado $ sudo apt install snapd # Mint/Zorin lo suelen traer ya $ sudo apt install flatpak $ flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo

Monitores del sistema
Para ver de un vistazo cómo está tu CPU, RAM, temperatura y qué hardware tienes
top comando clásico

El monitor de procesos original, presente en cualquier Linux sin instalar nada. Muestra en tiempo real la carga del sistema, uso de CPU y RAM, y la lista de procesos ordenada por consumo. No es tan bonito como btop, pero es el que vas a encontrar siempre que te conectes a un servidor por SSH — por eso conviene dominarlo aunque uses btop a diario en tu propio equipo (ya lo viste a fondo en el Nivel 16 — Procesos).

Para qué sirve
Ver carga, CPU, RAM y procesos en tiempo real
Cómo se ejecuta
top
Teclas útiles
M ordena por RAM, P por CPU, q para salir
Instalar
ya viene instalado siempre
top
$ top # Dentro de top: "M" ordena por memoria, "P" por CPU, "1" muestra cada núcleo # por separado, "k" mata un proceso pidiendo su PID, "q" sale # Truco: "top -o %MEM" arranca ya ordenado por memoria
btop monitor de recursos

El sucesor visual de top/htop. Muestra CPU (por núcleo), RAM, swap, disco, red y procesos con gráficas de barras en tiempo real, todo con el ratón y el teclado. Es prácticamente el estándar hoy en día para monitorizar un sistema Linux desde la terminal.

Para qué sirve
Ver CPU/RAM/disco/red/procesos en vivo, con gráficas
Cómo se ejecuta
btop
Salir
tecla q
Instalar (Mint/Zorin/Voyager)
sudo apt install btop
btop
$ sudo apt update && sudo apt install btop $ btop # Dentro de btop: flechas para moverte por los procesos, "k" mata un proceso, # "m" cambia el modo de vista, "+/-" ajusta el zoom del panel, "esc" abre el menú de opciones
fastfetch info del sistema

Muestra un resumen bonito de tu sistema (distro, kernel, CPU, GPU, RAM, resolución, tema, uptime...) junto al logo ASCII de tu distro, en cuanto abres la terminal. Es el sustituto moderno y mucho más rápido de neofetch (que dejó de mantenerse activamente).

Para qué sirve
Resumen visual del hardware y software instalado
Cómo se ejecuta
fastfetch
Instalar (Mint/Zorin/Voyager)
sudo apt install fastfetch
Si tu versión es antigua
añade el PPA/repo oficial de fastfetch en GitHub
fastfetch — presumir tu setup
$ sudo apt install fastfetch $ fastfetch # Truco: añade "fastfetch" al final de tu ~/.bashrc para verlo # cada vez que abras una terminal nueva $ echo "fastfetch" >> ~/.bashrc
neofetch info del sistema (clásico)

El clásico que popularizó eso de mostrar el logo de tu distro en ASCII junto a los datos del sistema al abrir la terminal — durante años fue LA herramienta para esto. Su desarrollo se detuvo en 2024, por lo que hoy se recomienda fastfetch (mismo resultado visual, más rápido y mantenido), pero sigue funcionando perfectamente y muchísimos tutoriales y configuraciones (dotfiles) que encontrarás en internet todavía lo usan, así que vale la pena conocerlo.

Para qué sirve
Lo mismo que fastfetch: resumen visual del sistema
Cómo se ejecuta
neofetch
Instalar (Mint/Zorin/Voyager)
sudo apt install neofetch
Estado
sin mantenimiento activo desde 2024
neofetch vs fastfetch
$ sudo apt install neofetch $ neofetch # Personalizar qué información muestra: $ nano ~/.config/neofetch/config.conf # Si el paquete no existe o quieres el reemplazo moderno, usa fastfetch # (misma idea, más rápido y con mantenimiento activo — ver tarjeta anterior)
glances monitor todo-en-uno

Como btop pero orientado a diagnóstico y a servidores: en una sola pantalla resume CPU, RAM, disco, red, sensores de temperatura, procesos y hasta contenedores Docker. Incluso puedes exponerlo como servidor web para monitorizar una máquina remota desde el navegador.

Cómo se ejecuta
glances
Instalar
sudo apt install glances
🔎
Explorar y conocer tu sistema
Comandos para saber exactamente qué hardware tienes y cuánto llevas encendido, sin abrir ninguna app gráfica

Antes de instalar nada extra, Linux ya trae comandos que te dicen con detalle qué CPU, discos, memoria y dispositivos tiene tu equipo. Son ideales para "entender" de verdad tu sistema, comparar especificaciones o diagnosticar un problema de hardware.

lscpu
Toda la información de tu procesador: modelo, núcleos, hilos, frecuencia, caché y arquitectura.
lscpu
lsblk
Lista discos y particiones en forma de árbol, con tamaño y dónde está montado cada uno.
lsblk -f
lsusb
Lista todos los dispositivos conectados por USB (ratón, teclado, pendrives, webcam...).
lsusb
lspci
Lista el hardware conectado por PCI: tarjeta gráfica, red, sonido, chipset.
lspci | grep -i vga
free -h
Memoria RAM y swap: total, usada, libre y en caché, en formato legible.
free -h
uname -a
Versión del kernel, arquitectura (x86_64/arm64) y nombre del equipo, todo en una línea.
uname -a
uptime
Cuánto tiempo lleva encendido el sistema y la carga media (load average) del 1, 5 y 15 min.
uptime -p
tree
Dibuja la estructura de carpetas y archivos como un árbol visual, en vez de listar plano.
tree -L 2 ~/Proyectos
inxi ficha técnica completa

El comando definitivo para conocer tu equipo a fondo: junta en un solo reporte CPU, GPU, RAM, discos, red, temperaturas y hasta la versión exacta de tu escritorio (Cinnamon, GNOME, XFCE...). Es lo primero que piden en foros de soporte de Linux Mint/Zorin cuando reportas un problema, porque describe el sistema completo en un solo comando.

Para qué sirve
Ficha técnica completa del equipo, ideal para pedir ayuda en foros
Cómo se ejecuta
inxi -Fxz
Instalar (Mint/Zorin/Voyager)
sudo apt install inxi
inxi — informe completo del sistema
$ sudo apt install inxi $ inxi -Fxz # -F = full report, -x = detalles extra, -z = oculta datos sensibles (MAC, serie) # Solo la tarjeta gráfica y el driver que está usando: $ inxi -G
combinar varios de un tirón
$ lscpu | grep "Model name" $ lsblk -f NAME FSTYPE LABEL SIZE MOUNTPOINT sda ├─sda1 vfat 512M /boot/efi └─sda2 ext2 118G / $ free -h total used free shared buff/cache available Mem: 15Gi 5.2Gi 4.1Gi 412Mi 5.7Gi 9.3Gi

💡 watch — repetir un comando en vivo

Si quieres ver cómo cambia la salida de un comando cada pocos segundos sin instalar nada nuevo, antepón watch: por ejemplo watch -n 2 free -h repite free -h cada 2 segundos, refrescando la pantalla. Funciona con cualquier comando (watch -n 1 sensors, watch df -h...) y es una alternativa rápida cuando no quieres abrir btop solo para vigilar un valor.

Disco y almacenamiento
df -h ya lo conoces del nivel 18 — estas herramientas te dicen exactamente qué se está comiendo el espacio
df -h comando clásico

Viene instalado siempre, sin excepción. Muestra el espacio total, usado y libre de cada partición o punto de montaje, en formato legible (-h = human-readable: GB/MB en vez de bloques). Es lo primero que ejecutas cuando sospechas que te estás quedando sin espacio.

df -h
$ df -h Filesystem Size Used Avail Use% Mounted on /dev/sda2 118G 42G 70G 38% / /dev/sda1 512M 88M 424M 18% /boot/efi tmpfs 7.8G 1.2M 7.8G 1% /run # Solo el sistema de archivos donde vive tu carpeta actual $ df -h . # Excluir tmpfs/udev para ver solo discos reales $ df -h -x tmpfs -x devtmpfs
ncdu analizador de espacio interactivo

df -h te dice CUÁNTO espacio libre tienes. ncdu (NCurses Disk Usage) te dice QUÉ carpeta se lo está comiendo — navegas visualmente por tu disco, ordenado de mayor a menor, y puedes borrar archivos directamente desde ahí. Es la herramienta número uno cuando el disco se llena y no sabes por qué.

Cómo se ejecuta
ncdu /ruta (o ncdu / con sudo)
Instalar
sudo apt install ncdu
Borrar dentro de ncdu
tecla d sobre el archivo/carpeta
ncdu — encontrar qué ocupa el disco
$ sudo apt install ncdu $ sudo ncdu / # analiza todo el sistema (tarda un poco) $ ncdu ~ # solo tu carpeta personal, más rápido # Flechas para navegar, Enter para entrar a una carpeta, # "d" para borrar lo seleccionado, "q" para salir
duf df moderno

Un df -h con colores, agrupado por tipo de disco (local, red, temporal) y con barras de uso. No reemplaza a ncdu (ese busca archivos grandes), pero da un vistazo más claro que df -h cuando tienes muchas particiones o discos montados.

Cómo se ejecuta
duf
Instalar
sudo apt install duf
⚡
Productividad en la shell
Herramientas que te ahorran teclas y te salvan de tus propios typos
thefuck corrector de comandos

Escribes mal un comando (get status en vez de git status, o te olvidas del sudo), lo ejecutas, falla — y en vez de reescribirlo, tecleas fuck y te sugiere el comando corregido para que solo pulses Enter. Aprende de tus errores más frecuentes con el tiempo.

Para qué sirve
Corregir automáticamente el último comando fallido
Cómo se ejecuta
fuck (tras un comando fallido)
Instalar
sudo apt install thefuck
Requiere
añadir una línea a ~/.bashrc para activarlo
thefuck
$ sudo apt install thefuck # Activarlo — añade esta línea al final de ~/.bashrc $ echo 'eval $(thefuck --alias)' >> ~/.bashrc $ source ~/.bashrc # Ejemplo de uso real: $ sudo pacman -Syu bash: sudo: command not found... o falla por permisos $ fuck sudo apt update && sudo apt upgrade [enter/↑/↓/ctrl+c]
fzf buscador difuso

Un buscador interactivo de "fuzzy finding": escribes unas pocas letras y filtra en tiempo real entre archivos, historial de comandos o lo que le pases por tubería. Se integra con Ctrl+R (buscar en el historial de bash) y Ctrl+T (buscar archivos) una vez configurado.

Cómo se ejecuta
fzf (o Ctrl+R / Ctrl+T tras configurarlo)
Instalar
sudo apt install fzf
fzf
$ sudo apt install fzf # Buscar un archivo entre miles y abrirlo con nano $ nano $(find ~ -type f | fzf) # Ctrl+R ahora abre un buscador difuso de tu historial de comandos
zoxide cd inteligente

Sustituye a cd. Recuerda las carpetas que más visitas y te deja saltar a ellas escribiendo solo un fragmento del nombre, sin importar en qué punto del sistema estés. Después de usarlo un par de semanas, escribes z proyecto en vez de cd ~/Documentos/trabajo/2026/proyecto.

Cómo se ejecuta
z nombre-parcial-de-carpeta
Instalar
sudo apt install zoxide
tldr manuales resumidos

man comando es completísimo pero denso. tldr comando muestra 5-8 ejemplos prácticos de uso real, sin rodeos. Perfecto cuando ya sabes lo que hace un comando pero no recuerdas la sintaxis exacta.

Cómo se ejecuta
tldr tar
Instalar
sudo apt install tldr
🔁
Reemplazos modernos de comandos clásicos
Mismo trabajo, con colores, resaltado de sintaxis y mejor rendimiento

Existe toda una familia de herramientas escritas en Rust que reimplementan comandos de toda la vida, casi siempre con el mismo nombre corto de una letra distinta. No son obligatorias, pero una vez las pruebas cuesta volver.

eza — reemplaza a ls
Listado de archivos con colores por tipo, iconos, árbol de directorios y estado de git integrado.
eza -la --icons --git
bat — reemplaza a cat
Muestra archivos con resaltado de sintaxis, números de línea y paginado automático.
bat script.sh
ripgrep (rg) — reemplaza a grep
Búsqueda de texto en archivos, muchísimo más rápida, respeta .gitignore automáticamente.
rg "TODO" --type py
fd — reemplaza a find
Buscar archivos por nombre con sintaxis simple, sin necesidad de flags raros como -name.
fd informe .pdf
instalar los reemplazos modernos
# En apt, ripgrep y fd-find suelen estar con nombre distinto: $ sudo apt install ripgrep fd-find bat # En Debian/Ubuntu el binario de fd-find se llama "fdfind", no "fd" $ fdfind informe.pdf # En Debian/Ubuntu el binario de bat se llama "batcat" $ batcat script.sh # eza normalmente no está en los repos base de Mint/Zorin/Voyager todavía, # se instala desde su repo oficial (ver instrucciones en github.com/eza-community/eza)

💡 Crea alias para no escribir el nombre largo

Añade esto a tu ~/.bashrc para que ls y find usen las versiones modernas sin cambiar tu costumbre: alias ls='eza --icons' y alias find='fdfind'. Así sigues escribiendo lo de siempre pero obtienes la herramienta nueva por debajo.

🪟
tmux — multiplexor de terminal
Varias terminales dentro de una sola ventana, que sobreviven aunque cierres la sesión

tmux te deja dividir una terminal en paneles, crear varias "pestañas" (ventanas) y, sobre todo, dejar procesos corriendo en segundo plano y volver a conectarte más tarde exactamente donde lo dejaste — imprescindible cuando trabajas por SSH en un servidor y no quieres que se corte el proceso si se cae la conexión.

Cómo se ejecuta
tmux
Instalar
sudo apt install tmux
tmux — lo esencial
$ tmux new -s trabajo # crea una sesión llamada "trabajo" # Ctrl+b luego " → divide el panel horizontalmente # Ctrl+b luego % → divide el panel verticalmente # Ctrl+b luego flechas → moverte entre paneles # Ctrl+b luego d → desconectar (detach) sin cerrar nada $ tmux ls # ver sesiones activas $ tmux attach -t trabajo # volver a conectar donde lo dejaste

Solo por diversión
No hacen nada útil, pero son parte de la cultura de la terminal — y sirven para practicar apt
cmatrix
La lluvia de caracteres verdes de "The Matrix" corriendo en tu terminal.
sudo apt install cmatrix && cmatrix
cowsay
Una vaca ASCII (o pingüino, dragón...) que "dice" el texto que le pases.
cowsay "Hola Hugo"
lolcat
Colorea de arcoíris cualquier salida de texto que le pases por tubería.
fortune | cowsay | lolcat
figlet
Convierte texto en letras gigantes hechas de caracteres ASCII.
figlet "Cafe"
combo clásico
$ sudo apt install cmatrix cowsay lolcat figlet fortune-mod $ fortune | cowsay | lolcat (una frase random, dicha por una vaca ASCII, en arcoíris)
✏️ Ejercicio del Nivel 24 Práctica

Monta tu propia caja de herramientas de terminal:

  1. Instala tres: ejecuta sudo apt update y luego instala btop, fastfetch y ncdu. Abre cada uno y explóralos un par de minutos.
  2. Diagnóstico real: usa ncdu ~ para encontrar qué carpeta de tu directorio personal ocupa más espacio. Compáralo con lo que te dice df -h .
  3. Automatiza tu bienvenida: añade fastfetch al final de tu ~/.bashrc para que se muestre cada vez que abras una terminal.
  4. thefuck en acción: instálalo, actívalo en ~/.bashrc, escribe intencionadamente mal un comando (por ejemplo sl -la en vez de ls -la) y corrígelo con fuck.
  5. Elige tu favorita: de todas las herramientas de este nivel, instala la que más te llamó la atención y créale un alias corto en ~/.bashrc para usarla sin escribir el nombre completo.

Reto: combina fortune | cowsay | lolcat y añádelo también a tu ~/.bashrc, justo antes de fastfetch, para tener una terminal con personalidad propia cada vez que la abras.

🟥 Resumen del Nivel 24

  • En Linux Mint, Zorin OS y Voyager todo se instala igual, con sudo apt install paquete, porque los tres comparten base Ubuntu/Debian.
  • Monitores: top (el clásico, siempre disponible), btop (su versión visual moderna), fastfetch y neofetch (resumen del sistema al abrir terminal — fastfetch es el reemplazo activo de neofetch), glances (todo-en-uno, útil en servidores).
  • Explorar hardware: lscpu, lsblk, lsusb, lspci, free -h, uname -a y uptime para datos puntuales; inxi -Fxz para una ficha técnica completa del equipo de un solo comando.
  • Disco: df -h dice cuánto espacio libre queda, ncdu dice qué carpeta se lo está comiendo, duf es un df con colores.
  • Productividad: thefuck corrige el último comando fallido, fzf busca de forma difusa, zoxide es un cd con memoria, tldr da ejemplos rápidos de cualquier comando.
  • Reemplazos modernos: eza (ls), bat/batcat (cat), rg/ripgrep (grep), fdfind (find) — en Debian/Ubuntu algunos cambian de nombre de binario.
  • tmux — paneles y sesiones de terminal que sobreviven aunque se corte la conexión SSH.
  • Ninguna de estas herramientas es obligatoria: los comandos clásicos del nivel 12-19 siempre funcionan, en cualquier máquina, aunque no puedas instalar nada.
