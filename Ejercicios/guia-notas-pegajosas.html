PARTE 1 — Vocabulario nuevo de JavaScript
Estas palabras van a aparecer todo el tiempo, apréndetelas antes de escribir código

¿Qué es un Array?

Un array es una lista ordenada de datos, escrita entre corchetes [ ] y separada por comas. Piensa en él como una fila de casilleros numerados, donde el primero es el casillero 0.

JSconst materias = ["Cálculo", "Historia", "Programación"];

🎒 Analogía: los casilleros de un lócker

Un array es como una fila de casilleros numerados en un gimnasio. El casillero 0 tiene tu primer objeto, el casillero 1 el segundo, y así. Para sacar algo, dices el número: materias[0] te da "Cálculo".

¿Qué es un Objeto?

Un objeto agrupa varios datos relacionados bajo un nombre, escrito entre llaves { } con pares propiedad: valor. Es perfecto para describir "una cosa" con varias características.

JSconst nota = { titulo: "Cálculo I", color: "amarillo", emoji: "📐" };

🪪 Analogía: una credencial

Un objeto es como tu credencial de estudiante: tiene varios campos (nombre, matrícula, carrera) todos pegados en una sola tarjeta. Accedes a cada dato con un punto: nota.titulo te da "Cálculo I".

¿Qué es el DOM?

El DOM (Document Object Model) es la representación en memoria de tu página HTML, con la que JavaScript puede hablar directamente: crear elementos, borrarlos, cambiarles el texto o el estilo — todo sin recargar la página.

💡 La idea central de este proyecto

En vez de escribir cada nota a mano en el HTML, vas a escribir los datos en un array de JavaScript, y una función va a recorrer ese array y construir el HTML de cada nota usando el DOM. Cambiar una nota es editar un objeto, no buscar y editar HTML.

¿Qué es un Evento?

Un evento es algo que pasa en la página — un clic, pasar el mouse, cambiar el tamaño de la ventana. Con addEventListener le dices a JavaScript "cuando pase esto, ejecuta esta función".

JSboton.addEventListener("click", function () { // esto se ejecuta cada vez que hacen clic en boton });

PARTE 3 — El HTML
Un esqueleto muy corto a propósito: casi todo lo va a construir JavaScript

Bloque 1 — La base del documento

🧪 Reto

Escribe la estructura mínima de un HTML5: doctype, <html lang="es">, <head> con charset, viewport y title, enlace a css/style.css, y un <body> vacío.

HTML<!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Mis Notas</title> <link rel="stylesheet" href="css/style.css"> </head> <body> </body> </html>

💡 ¿Por qué el link va antes de cerrar head?

El navegador lee de arriba hacia abajo. Poniendo el CSS en <head>, se carga antes de mostrar el contenido — así evitas ese parpadeo feo donde la página aparece sin estilos por medio segundo.

Bloque 2 — Encabezado y contenedor vacío

🧪 Reto

Dentro del <body>, agrega un <header> con un <h1> (el título de tu app) y un <button> con id="btn-agregar". Debajo, agrega un <main> con id="contenedor-notas", vacío a propósito.

HTML<header> <h1>📌 Mis materias</h1> <button id="btn-agregar">+ nueva nota</button> </header> <main id="contenedor-notas"></main> <script src="js/script.js"></script>

💡 ¿Por qué el contenedor está vacío?

Porque no vas a escribir las notas a mano. JavaScript va a leer tu array de datos y meter cada nota ahí dentro. Si ves este <main> vacío en el HTML, es correcto — así debe estar.

⚠️ El script va al final del body

Si pones <script> en el <head>, JavaScript intentaría buscar el <main> antes de que exista, y fallaría. Ponerlo al final del <body> garantiza que todo el HTML ya está cargado.

PARTE 4 — El CSS
Reset, layout de columnas y el estilo de la tarjeta "post-it"

Bloque 1 — Reset y fondo

🧪 Reto

En css/style.css, escribe un reset universal (margin, padding, box-sizing) y el estilo base del body con una tipografía y un color de fondo tipo "corcho".

CSS* { margin: 0; padding: 0; box-sizing: border-box; } body { font-family: 'Segoe UI', sans-serif; background-color: #f4f1ea; min-height: 100vh; padding: 40px 20px; }

💡 ¿Por qué box-sizing: border-box?

Sin esto, el padding y el borde se suman al ancho que definas, y calcular tamaños se vuelve un dolor de cabeza. Con border-box, el ancho que pones ya incluye padding y borde — es el estándar en casi todo proyecto moderno.

Bloque 2 — El contenedor en columnas (layout tipo muro)

🧪 Reto

Dale a #contenedor-notas un display: flex con gap, y crea una clase .columna que sea también flex, en columna, con su propio gap. Este contenedor no va a tener las notas directas — va a tener 3 columnas, y cada columna va a tener sus notas.

CSS#contenedor-notas { max-width: 900px; margin: 0 auto; display: flex; align-items: flex-start; gap: 20px; } .columna { flex: 1; display: flex; flex-direction: column; gap: 20px; min-width: 0; }

🧱 Analogía: 3 pilas de cartas

En vez de repartir las notas en una sola cuadrícula (donde una nota alta deja huecos al lado), piensa en 3 pilas verticales. Cada nota nueva se va a la pila más corta en ese momento, así todas las pilas crecen parejo — como cuando repartes cartas a 3 jugadores intentando que nadie tenga muchas más que otro.

⚠️ ¿Por qué no usar CSS Grid o column-count?

display: grid estira todas las notas de una fila a la altura de la más alta — deja huecos feos. column-count reparte de arriba hacia abajo en cada columna antes de pasar a la siguiente, no de izquierda a derecha. Ninguno de los dos hace lo que buscas con solo CSS — por eso, más adelante, JavaScript va a decidir en qué columna va cada nota.

Bloque 3 — La tarjeta de nota

🧪 Reto

Crea la clase .nota con padding, bordes redondeados, una altura fija de 180px, overflow: hidden, sombra suave y cursor: pointer. Usa display: flex; flex-direction: column; para acomodar el título y el texto verticalmente.

CSS.nota { padding: 18px; border-radius: 4px; height: 180px; overflow: hidden; box-shadow: 0 4px 10px rgba(0,0,0,.15); display: flex; flex-direction: column; gap: 8px; cursor: pointer; transform: rotate(var(--rotacion, 0deg)); }

💡 ¿Qué es var(--rotacion, 0deg)?

--rotacion es una variable CSS personalizada, distinta en cada nota. Aquí no le damos un valor fijo — JavaScript se lo va a asignar a cada tarjeta con un número aleatorio, para el efecto "post-it real" con leve inclinación. El 0deg es el valor por defecto, por si alguna nota no la tiene.

Ahora el :hover — que la nota se enderece y crezca un poco al pasar el mouse:

CSS.nota:hover { transform: rotate(0deg) scale(1.03); box-shadow: 0 8px 16px rgba(0,0,0,.22); z-index: 5; }

Bloque 4 — Recortar texto largo (line-clamp)

🧪 Reto

Dentro de .nota p, usa -webkit-line-clamp para que el texto se corte después de 5 líneas y no rompa el tamaño fijo de la tarjeta.

CSS.nota p { font-size: 14px; line-height: 1.4; white-space: pre-line; display: -webkit-box; -webkit-line-clamp: 5; -webkit-box-orient: vertical; overflow: hidden; }

💡 ¿Por qué white-space: pre-line?

Por defecto, HTML ignora los saltos de línea del texto. pre-line le dice al navegador "respeta los \n que vengan del texto" — así puedes escribir notas con varias líneas en tu array de JS.

Bloque 5 — Nota expandida (clic para ver todo)

🧪 Reto

Crea una clase .nota--expandida que quite la altura fija, y otra regla .nota--expandida p que anule el line-clamp para mostrar el texto completo.

CSS.nota--expandida { height: auto; min-height: 180px; z-index: 10; } .nota--expandida p { -webkit-line-clamp: unset; display: block; overflow: visible; }

💡 Esta clase no hace nada todavía

Aquí solo defines cómo se ve una nota con esa clase. Quién agrega y quita la clase al hacer clic es JavaScript — lo vas a conectar en la siguiente parte.

Bloque 6 — Colores y animación de entrada

🧪 Reto

Crea al menos 5 clases de color pastel (una por línea, solo background-color). Después, escribe un @keyframes aparecer que anime opacidad y una pequeña traslación/escala al aparecer.

CSS.amarillo { background-color: #fdf1a1; } .verde { background-color: #c9f2c0; } .rosa { background-color: #f9c9dd; } .celeste { background-color: #bfe6f7; } .lila { background-color: #dcc9f2; } @keyframes aparecer { from { opacity: 0; transform: translateY(15px) rotate(var(--rotacion, 0deg)) scale(.9); } to { opacity: 1; transform: translateY(0) rotate(var(--rotacion, 0deg)) scale(1); } }

Y en .nota, activa esa animación agregando estas 2 líneas:

CSSopacity: 0; animation: aparecer .4s ease forwards;

💡 ¿Qué hace forwards?

Sin forwards, al terminar la animación el elemento regresaría a su estado antes de animarse (invisible otra vez). forwards le dice "quédate en el estado final" — visible, en su posición normal.

PARTE 5 — El JavaScript
Aquí vive el corazón del proyecto: datos + funciones que dibujan y reaccionan

Bloque 1 — El array de datos

🧪 Reto

En js/script.js, crea const notas = [ ] con al menos 4 objetos. Cada uno con titulo, texto y color. Agrega emoji a alguna, para practicar un campo opcional.

JSconst notas = [ { titulo: "Cálculo I", texto: "Repasar límites.", color: "amarillo", emoji: "📐" }, { titulo: "Historia", texto: "Leer capítulo 5.", color: "rosa" } ];

Bloque 2 — Crear una nota en HTML

🧪 Reto

Escribe una función crearElementoNota(nota) que reciba un objeto, cree un <article> con document.createElement, le agregue las clases "nota" y el color, y meta el título y texto con innerHTML usando template literals.

JSfunction crearElementoNota(nota) { const articulo = document.createElement("article"); articulo.classList.add("nota", nota.color); articulo.innerHTML = ` <h3>${nota.titulo}</h3> <p>${nota.texto}</p> `; return articulo; }

💡 ¿Qué son las comillas invertidas ` `?

Se llaman template literals. A diferencia de las comillas normales, te dejan insertar variables directo dentro del texto con ${ } — sin tener que concatenar con +. Y también respetan saltos de línea reales.

Ahora agrega el emoji opcional y una rotación aleatoria antes del return:

JS// rotación aleatoria entre -3 y 3 grados const rotacionAleatoria = (Math.random() * 6 - 3).toFixed(1); articulo.style.setProperty("--rotacion", rotacionAleatoria + "deg");
JS// dentro del innerHTML, cambia el <h3> por esta línea: <h3>${nota.emoji ? nota.emoji + " " : ""}${nota.titulo}</h3>

❓ Analogía: el operador ternario

condición ? sivalorEsVerdadero : sivalorEsFalso es un "if" en una sola línea. Aquí dice: "si la nota tiene emoji, pon el emoji y un espacio; si no, no pongas nada". Como un semáforo con solo 2 caminos.

Bloque 3 — Dibujar todas las notas en columnas

🧪 Reto

Escribe una función numeroDeColumnas() que devuelva 1, 2 o 3 según el ancho de la ventana. Luego escribe renderizarNotas(): crea esa cantidad de <div class="columna">, y por cada nota del array, busca la columna con menor altura (offsetHeight) y mete la nota ahí.

JSfunction numeroDeColumnas() { const ancho = window.innerWidth; if (ancho <= 480) return 1; if (ancho <= 700) return 2; return 3; } function renderizarNotas() { const contenedor = document.getElementById("contenedor-notas"); contenedor.innerHTML = ""; const columnas = []; for (let i = 0; i < numeroDeColumnas(); i++) { const columna = document.createElement("div"); columna.classList.add("columna"); columnas.push(columna); contenedor.appendChild(columna); } notas.forEach(function (nota, indice) { const elemento = crearElementoNota(nota); elemento.style.animationDelay = (indice * 0.08) + "s"; let columnaMasCorta = columnas[0]; columnas.forEach(function (columna) { if (columna.offsetHeight < columnaMasCorta.offsetHeight) { columnaMasCorta = columna; } }); columnaMasCorta.appendChild(elemento); }); }

💡 ¿Por qué buscar la columna "más corta" cada vez?

offsetHeight te da la altura real en píxeles de un elemento en ese instante. Comparando las 3 columnas antes de cada nota, siempre mandas la próxima nota a la que va más atrasada — así se rellenan parejo, como repartir cartas de una en una al jugador con menos cartas.

Bloque 4 — Expandir la nota con un clic

🧪 Reto

Dentro de crearElementoNota, antes del return, agrega un addEventListener("click", ...) que alterne la clase nota--expandida.

JSarticulo.addEventListener("click", function () { articulo.classList.toggle("nota--expandida"); });

💡 ¿Qué hace classList.toggle?

Es un interruptor. Si el elemento no tiene esa clase, se la pone; si ya la tiene, se la quita. Por eso un solo clic expande y el siguiente clic la vuelve a encoger — no necesitas dos funciones distintas.

Bloque 5 — Botón "+ nueva nota" y arranque

🧪 Reto

Conecta el botón: al hacer clic, agrega un objeto nuevo al array con push() y vuelve a llamar renderizarNotas(). Al final del archivo, llama renderizarNotas() una vez para que las notas aparezcan al cargar, y agrega un listener de resize para reacomodar si cambia el tamaño de ventana.

JSdocument.getElementById("btn-agregar").addEventListener("click", function () { const colores = ["amarillo", "verde", "rosa", "celeste", "lila"]; const colorAleatorio = colores[Math.floor(Math.random() * colores.length)]; notas.push({ titulo: "Nueva nota", texto: "Escribe aquí...", color: colorAleatorio }); renderizarNotas(); }); renderizarNotas(); window.addEventListener("resize", renderizarNotas);

✅ Con esto tu proyecto ya funciona completo

Ábrelo en el navegador. Deberías ver tus notas repartidas en columnas parejas, con colores, poder hacer clic para expandir una nota larga, y que el botón agregue notas nuevas.
