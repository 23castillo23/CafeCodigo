Mapa HTML ↔ CSS

      
Lo que se escribe en un lado, se escribe distinto en el otro

    

  

  

    
SelectorEn el HTMLEn el CSSA quién aplica

    
Etiqueta<h1>h1 { }A todos los <h1>

    
Claseclass="plato".plato { }A todos los que tengan esa clase

    
Idid="logo"#logo { }A uno solo (el id no se repite)

  

  
☕ Analogía
Las clases son el uniforme de los meseros: varios lo llevan. El id es el gafete con nombre: solo uno lo tiene. La etiqueta es el puesto: "todos los cocineros".
