🎥 MIS GUIAS

🧩 GUÍAS ADICIONALES

Fuera de la ruta principal

Café </> está centrado en HTML, CSS y JavaScript — pero a veces hace falta aprender algo de al lado del camino: la terminal, bases de datos, herramientas. Aquí vive todo eso.

💡

¿Cómo funciona?

Guías completas sobre temas complementarios a la ruta principal, con el mismo formato de siempre: analogías, ejemplos y ejercicios. Perfectas para cuando necesitas una habilidad de apoyo — como moverte en la terminal o escribir consultas SQL — sin que eso interrumpa el flujo de HTML/CSS/JS.

🧠 DATOS CURIOSOS

Cosas que se aprenden cuando uno no sabe cómo funciona algo

Este no es un capítulo con ejercicios ni código para practicar. Es el rincón para el "espera, ¿así funciona esto?" — cómo piensa un procesador, qué diferencia una RAM de otra, por qué existen tantos tipos de chips. Curiosidad pura sobre lo que hay detrás de la pantalla.

💡

¿Cómo funciona?

Guías completas de fundamentos de hardware y computación, con el mismo formato de siempre: analogías, ejemplos y sin código que memorizar. No necesitas saber programar para entenderlas — solo curiosidad.

🖥️ CONSOLAS · HERRAMIENTAS

Entorno de práctica

Tu laboratorio interactivo para escribir y ejecutar código. HTML, CSS, JavaScript, Python y Java directamente en el navegador, sin instalar nada.
