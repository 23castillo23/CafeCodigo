¿Qué es HTML?
El lenguaje con el que está construida toda la web

HTML significa HyperText Markup Language — Lenguaje de Marcado de Hipertexto. No es un lenguaje de programación: es un lenguaje de estructura. Le dice al navegador qué hay en la página y cómo organizarlo.

🦴
HTML = Esqueleto
Da la estructura y el contenido de la página.
🎨
CSS = Piel y ropa
Le da el estilo visual al esqueleto.
💪
JavaScript = Músculos
Le da movimiento e interactividad.

💡 Lo que dice HolaMundo

Nicolás lo explica así: HTML define qué es cada cosa (esto es un título, esto es un párrafo, esto es una imagen). CSS define cómo se ve cada cosa. Sin HTML no hay página web posible.

¿Cómo funciona una página web?

1
Escribes HTML en un archivo .html con tu editor de texto (VS Code)
2
El navegador lee ese archivo (Chrome, Firefox, Safari…)
3
El navegador interpreta las etiquetas y muestra el resultado visual en pantalla
4
Tú ves la página web — eso es todo lo que hay detrás de cualquier sitio web

Las etiquetas — el concepto fundamental

HTML trabaja con etiquetas. Una etiqueta es una instrucción entre < y >. La mayoría vienen en pares: una de apertura y una de cierre.

<!-- Etiqueta con apertura y cierre --> <etiqueta> contenido aquí </etiqueta> <!-- Ejemplos reales --> <h1>Esto es un título</h1> <p>Esto es un párrafo</p> <!-- Etiquetas que se cierran solas (auto-cierre) --> <img src="foto.jpg" /> <br /> <input />

Instalando VS Code — El editor de código
La herramienta que usan la mayoría de desarrolladores web

Para escribir HTML necesitas un editor de texto. El más popular en el mundo (y el que usa HolaMundo) es Visual Studio Code — es gratuito y tiene todo lo que necesitas.

1
Descarga VS Code desde code.visualstudio.com — elige tu sistema operativo (Windows, Mac o Linux)
2
Instálalo con las opciones por defecto
3
Instala la extensión "Live Server" — te permite ver los cambios en el navegador en tiempo real sin recargar manualmente

🟢 Extensión esencial: Live Server

En VS Code → panel de extensiones (ícono de 4 cuadros a la izquierda) → busca "Live Server" de Ritwick Dey → instalar. Con esto haces clic derecho en tu archivo HTML → "Open with Live Server" y se abre en el navegador actualizándose solo cada vez que guardas.

Creando el primer proyecto
Carpeta, archivo index.html y abrirlo en el navegador

Un proyecto web es simplemente una carpeta con archivos dentro. El archivo principal siempre se llama index.html — es el nombre que los navegadores y servidores buscan por defecto.

1
Crea una carpeta en tu escritorio o donde quieras. Nómbrala algo como mi-primera-web (sin espacios, en minúsculas)
2
Abre VS Code → Archivo → Abrir carpeta → selecciona tu carpeta
3
Crea un nuevo archivo dentro de la carpeta y nómbralo index.html
4
Escribe algo de HTML, guarda con Ctrl+S, y ábrelo con Live Server o arrastrándolo al navegador

⚠️ ¿Por qué index.html?

Cuando alguien entra a una web (por ejemplo google.com), el servidor busca automáticamente un archivo llamado index.html. Si lo llamas diferente, el servidor no lo encontrará. Siempre index.html como página principal.

🟢 Nombres de archivos y carpetas — reglas de oro

  • Todo en minúsculas: mi-pagina.html no MiPagina.html
  • Sin espacios: usa guion (-) en vez de espacio
  • Sin acentos ni ñ: pagina.html no página.html
  • La extensión siempre .html

Primeros pasos — La estructura base del HTML
El esqueleto mínimo que todo archivo HTML debe tener

Todo archivo HTML válido tiene la misma estructura base. En VS Code puedes generarla automáticamente escribiendo ! y presionando Tab (es un atajo de Emmet).

La estructura mínima

<!DOCTYPE html>Declaración — "esto es HTML5" <html lang="es">Raíz — contiene TODO <head>Cabeza — info para el navegador (no visible) <meta charset="UTF-8"> <title>Mi primera web</title> </head> <body>Cuerpo — todo lo que el usuario VE Aquí va tu contenido... </body> </html>

¿Qué hace cada parte?

EtiquetaQué esDetalles
<!DOCTYPE html>Declaración del tipo de documentoLe dice al navegador que use HTML5. Siempre va en la primera línea. No es una etiqueta HTML propiamente, es una instrucción.
<html>Elemento raízContiene absolutamente todo el documento. El atributo lang="es" indica el idioma (importante para accesibilidad y SEO).
<head>Cabecera del documentoContiene información para el navegador que el usuario NO ve directamente: charset, título, links a CSS, metadatos.
<meta charset>Codificación de caracteresCon UTF-8 puedes usar acentos, ñ y cualquier carácter especial sin problemas. Siempre ponla.
<title>Título de la pestañaLo que aparece en la pestaña del navegador y en los resultados de Google. Debe ser descriptivo.
<body>Cuerpo del documentoTODO lo que el usuario ve en la página va aquí: textos, imágenes, botones, formularios, todo.

El código generado por el atajo ! + Tab en VS Code

<!-- Escribe ! y presiona Tab en VS Code --> <!-- Resultado: --> <!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Document</title> </head> <body> </body> </html> <!-- Cambia lang="en" por lang="es" si tu web es en español --> <!-- Cambia "Document" en title por el nombre real de tu página -->

🟢 La regla de la indentación

Todo lo que va dentro de una etiqueta debe tener un nivel más de sangría (Tab). Las etiquetas anidadas son más fáciles de leer y menos propensas a errores cuando están bien indentadas. VS Code con Alt+Shift+F lo hace automático.

Ejercicio — Tu primera página HTML
Pon en práctica todo lo de la Parte A
✏️ Ejercicio Parte A — Primera página Principiante
  1. Crea una carpeta llamada repaso-html en tu escritorio.
  2. Ábrela con VS Code (Archivo → Abrir carpeta).
  3. Crea el archivo index.html dentro de la carpeta.
  4. Usa el atajo ! + Tab para generar la estructura base.
  5. Cambia lang="en" por lang="es".
  6. Cambia el título por "Mi primera página web".
  7. Dentro del <body> escribe: <h1>¡Hola Mundo!</h1>
  8. Guarda con Ctrl+S y ábrelo con Live Server.
  9. Verifica que en la pestaña del navegador aparezca "Mi primera página web" y en la página aparezca el texto en grande.

Bonus: Agrega debajo del h1 un párrafo con <p> que diga tu nombre y qué estás aprendiendo.

🟢 Lo que aprendiste en la Parte A

  • HTML es el lenguaje de estructura de la web — no es programación, es marcado
  • HTML usa etiquetas entre < y >, la mayoría con apertura y cierre
  • VS Code + Live Server = tu entorno de trabajo
  • Todo archivo HTML empieza con <!DOCTYPE html>
  • La estructura base: html → head (invisible) + body (visible)
  • <meta charset="UTF-8"> para soporte de acentos y ñ
  • <title> es lo que aparece en la pestaña del navegador
  • Todo lo que el usuario ve va dentro del <body>
  • El archivo principal siempre se llama index.html
