<div> — El contenedor genérico
La caja invisible que agrupa y organiza elementos

El <div> (division) es un contenedor genérico de bloque. No tiene ningún significado semántico ni estilo visual propio — es una caja invisible. Su único propósito es agrupar elementos para poder aplicarles CSS o manipularlos con JavaScript.

<!-- div solo: invisible, no hace nada visualmente --> <div> <h2>Título del artículo</h2> <p>Contenido del artículo...</p> <a href="#">Leer más</a> </div> <!-- El div agrupa h2 + p + a como "una sola unidad" --> <!-- Con CSS puedo darle fondo, borde, margen a TODO el grupo --> <!-- Es diferente a span: div es block, span es inline --> <p>Texto con una <span>palabra marcada</span> inline.</p>

🟢 div + id o class = el dúo más útil de HTML

Un div solo no hace nada. Un div con una clase o un id se convierte en el punto de entrada para CSS y JavaScript. La combinación <div class="articulo"> + regla CSS .articulo { ... } es el patrón más repetido en el desarrollo web real.

🏷️
Atributos id y class — Identificar y agrupar elementos
Los puentes entre HTML y CSS / JavaScript

Los atributos id y class son la forma de darle un nombre a los elementos HTML para poder referenciarlos desde CSS o JavaScript. Son los más usados de todos los atributos HTML.

<!-- id: identificador ÚNICO — solo un elemento puede tener ese id --> <div id="navbar">...</div> <div id="footer">...</div> <!-- En CSS: #navbar { ... } En JS: document.getElementById("navbar") --> <!-- class: nombre reutilizable — muchos elementos pueden tener la misma clase --> <div class="articulo">Artículo 1</div> <div class="articulo">Artículo 2</div> <div class="articulo">Artículo 3</div> <!-- En CSS: .articulo { ... } Aplica a los 3 elementos a la vez --> <!-- Un elemento puede tener múltiples clases separadas por espacio --> <div class="articulo destacado reciente">...</div> <!-- Tiene 3 clases: "articulo", "destacado" y "reciente" --> <!-- id y class juntos --> <div id="primer-post" class="articulo destacado">...</div>
HTML

🟢 En la práctica moderna: usa class casi siempre

En proyectos reales, los desarrolladores usan class para casi todo el CSS. El id se reserva principalmente para anclas de navegación y para cuando JavaScript necesita referenciar un elemento único. Esto es porque los selectores de clase son más flexibles y reutilizables.

Cómo se conectan HTML y CSS

<!-- HTML: defines la estructura y das nombres --> <div class="articulo"> <h2>Mi primer post</h2> <p class="fecha">15 de junio</p> </div> /* CSS: usas los nombres para aplicar estilos */ /* .articulo apunta a todos los elementos con class="articulo" */ .articulo { background: white; border: 1px solid #e0e0e0; border-radius: 8px; padding: 1.5rem; margin-bottom: 1rem; } /* .fecha apunta a elementos con class="fecha" */ .fecha { color: gray; font-size: 0.85rem; } /* #navbar apunta al elemento con id="navbar" */ #navbar { background: black; color: white; padding: 1rem; }

Etiquetas semánticas — La evolución del div
HTML5 introdujo etiquetas con significado propio para reemplazar al div

Aunque el blog de HolaMundo usa <div> para todo, HTML5 introdujo etiquetas semánticas que hacen exactamente lo mismo que un div pero con un significado claro. El navegador y Google las entienden mejor.

<!-- Con divs (como en el video de HolaMundo) --> <div id="navbar">...</div> <div id="contenido"> <div id="articulos">...</div> <div id="sidebar">...</div> </div> <div id="footer">...</div> <!-- Con etiquetas semánticas (la forma moderna) --> <!-- Misma estructura, más significado para buscadores y accesibilidad --> <nav>...</nav> <main> <section>...</section> <aside>...</aside> </main> <footer>...</footer>
HTML
Etiqueta semánticaReemplaza aCuándo usarla
<header><div id="header">Cabecera de la página o de una sección
<nav><div id="navbar">Menú de navegación principal
<main><div id="contenido">El contenido principal — solo uno por página
<section><div class="seccion">Una sección temática del contenido
<article><div class="articulo">Contenido independiente: post, noticia, comentario
<aside><div id="sidebar">Contenido secundario, relacionado pero no principal
<footer><div id="footer">Pie de la página o de una sección

🟢 ¿div o etiqueta semántica?

Usa la etiqueta semántica cuando existe una que describe lo que contiene. Usa <div> cuando solo necesitas un contenedor sin significado especial — por ejemplo, para agrupar elementos a los que quieres aplicar CSS sin que el grupo en sí signifique algo concreto.

Links revisitados — Trucos y patrones avanzados
Lo que HolaMundo explica al final del curso sobre los vínculos

HolaMundo cierra el curso revisando los links con más profundidad — especialmente cómo usarlos para navegar entre las páginas del blog y cómo usar el # para anclas dentro de la misma página.

<!-- NAVEGACIÓN ENTRE PÁGINAS DEL BLOG --> <!-- Desde index.html --> <a href="contacto.html">Ir a Contacto</a> <!-- Desde una subcarpeta (posts/post1.html) volver al inicio --> <a href="../index.html">← Volver al inicio</a> <!-- ANCLAS: navegar a secciones de la misma página --> <!-- El link (puede estar en la navbar) --> <a href="#sobre-mi">Sobre mí</a> <a href="#contacto">Contacto</a> <!-- El destino (más abajo en la misma página) --> <div id="sobre-mi"> <h2>Sobre mí</h2> ... </div> <div id="contacto"> <h2>Contacto</h2> ... </div> <!-- Link que no va a ningún lado todavía (placeholder) --> <a href="#">Próximamente</a> <!-- Link a otra página + ancla específica --> <a href="about.html#historia">Ver mi historia</a> <!-- Abre about.html y hace scroll hasta id="historia" -->
HTML
Tipos de href — resumen visual
href="pagina.html" Navega a otra página en el mismo sitio (ruta relativa)
href="../index.html" Sube un nivel de carpeta y va a index.html
href="https://..." Enlace a otro sitio web (ruta absoluta)
href="#seccion" Salta a un elemento con ese id en la misma página
href="#" Placeholder — no va a ningún lado, recarga la página
href="mailto:x@y.com" Abre el cliente de correo del usuario
href="tel:+52..." En móvil, marca el número directamente

Aplica todo lo del curso en un proyecto completo real
🏁 Proyecto Final — Blog personal con HTML puro Proyecto

Crea una carpeta mi-blog con la siguiente estructura y contenido:

Archivos a crear:

  • mi-blog/
  •   index.html (página principal)
  •   sobre-mi.html
  •   contacto.html
  •   img/ (carpeta con tu foto y otras imágenes)

index.html debe tener:

  1. Estructura base completa (DOCTYPE, html, head, body)
  2. Un <nav> o <div id="navbar"> con links a las 3 páginas
  3. Un <main> o <div id="contenido"> con mínimo 3 artículos usando class="articulo" en cada uno
  4. Cada artículo con: h2 del título, párrafo de fecha con class="fecha", párrafo de contenido, link "Leer más →"
  5. Un <aside> o sidebar con categorías como lista <ul>
  6. Un <footer> con tu nombre y el año

sobre-mi.html debe tener:

  1. La misma navbar que index.html (para mantener consistencia)
  2. Tu foto con <img>, alt descriptivo y width definido
  3. Tu nombre en un <h1>
  4. Párrafos sobre ti, lo que estudias y tus metas
  5. Una lista de tus habilidades con <ul>
  6. Link de regreso a inicio: <a href="index.html">← Inicio</a>

contacto.html debe tener:

  1. La misma navbar
  2. Un formulario completo: nombre, email, asunto (select), mensaje (textarea), checkbox de términos, botón enviar
  3. Tus redes sociales como links con target="_blank"
  4. Tu email como link mailto:

Bonus: Agrega anclas en index.html para que el link "Artículos" del navbar baje directamente a la sección de artículos usando href="#articulos" e id="articulos".

🟢 Resumen de la Parte E

  • Blog con HTML: navbar + contenido + sidebar + footer — todo con etiquetas ya conocidas
  • <div> — contenedor genérico de bloque, sin significado propio. Solo agrupa elementos para CSS/JS
  • id — identificador único. Solo uno por página. CSS: #id. Anclas: href="#id"
  • class — reutilizable. Muchos elementos pueden tener la misma clase. CSS: .clase
  • Un elemento puede tener varias clases: class="articulo destacado"
  • Etiquetas semánticas: <nav>, <main>, <section>, <article>, <aside>, <header>, <footer>
  • Links revisitados: rutas relativas, anclas #id, link a otra página + ancla pagina.html#seccion
  • href="#" — placeholder que no va a ningún lado (recarga la página)
