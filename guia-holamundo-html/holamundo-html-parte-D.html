<form> — Formularios
El contenedor que agrupa todos los campos de un formulario

Un formulario es el mecanismo principal para que el usuario envíe datos al servidor: login, registro, contacto, búsqueda, checkout. La etiqueta <form> es el contenedor que agrupa todos los campos.

<!-- Estructura básica de un formulario --> <form action="/enviar" method="POST"> <!-- Etiqueta vinculada al input --> <label for="nombre">Tu nombre:</label> <input type="text" id="nombre" name="nombre"> <label for="email">Tu email:</label> <input type="email" id="email" name="email"> <button type="submit">Enviar</button> </form>
HTML

Atributos del <form>

AtributoQué haceValores comunes
actionLa URL a donde se envían los datos al hacer submit"/login", "procesar.php"
methodCómo se envían los datosGET (en la URL) / POST (en el cuerpo, más seguro)
novalidateDesactiva la validación nativa del navegadorPara usar validación personalizada con JS

La etiqueta <label> — siempre vinculada al input

<!-- Método 1: for en label + id en input (el más común) --> <label for="usuario">Nombre de usuario:</label> <input type="text" id="usuario" name="usuario"> <!-- El for y el id deben ser IGUALES para que se vinculen --> <!-- Ventaja: al hacer clic en el label, se enfoca el input --> <!-- Método 2: input dentro del label --> <label> Nombre de usuario: <input type="text" name="usuario"> </label>
HTML

⚠️ Siempre vincula el label al input

Un input sin label es inaccesible para usuarios de lectores de pantalla. Además, el clic en el label enfoca el input, mejorando la experiencia del usuario — especialmente en checkboxes y radios donde el área de clic pequeña es difícil de usar.

Tipos de <input> — El campo que cambia de forma
Un solo elemento HTML con más de 20 tipos diferentes

La etiqueta <input> es de auto-cierre y cambia completamente de comportamiento según el valor del atributo type. Cada tipo tiene validación y teclado móvil optimizado.

type="text"

type="email"

type="password"
Oculta los caracteres
type="number"
Solo números, con flechas
type="date"
Selector de fecha
type="color"
Selector de color
type="range"
Deslizador de valor
type="search"
Campo de búsqueda (con X para borrar)

Inputs especiales: checkbox, radio y select

<!-- CHECKBOX: opciones múltiples (pueden seleccionarse varias) --> <input type="checkbox" id="html" name="skills" value="html"> <label for="html">HTML</label> <input type="checkbox" id="css" name="skills" value="css" checked> <label for="css">CSS (marcado por defecto)</label> <!-- RADIO: opciones únicas (solo se puede elegir una) --> <!-- Mismo name para que sean mutuamente excluyentes --> <input type="radio" id="basico" name="nivel" value="basico"> <label for="basico">Básico</label> <input type="radio" id="avanzado" name="nivel" value="avanzado"> <label for="avanzado">Avanzado</label> <!-- SELECT: lista desplegable --> <select name="pais" id="pais"> <option value="">-- Selecciona tu país --</option> <option value="mx">México</option> <option value="ar" selected>Argentina (seleccionado)</option> <option value="co">Colombia</option> </select> <!-- TEXTAREA: texto largo de varias líneas --> <textarea name="mensaje" id="mensaje" rows="4" cols="40"> Texto inicial opcional </textarea>

<button> — Botones
El elemento interactivo más común de la web

La etiqueta <button> crea un botón en el que el usuario puede hacer clic. A diferencia de <input type="button">, el <button> puede contener HTML dentro (íconos, imágenes, texto con estilos).

<!-- type="submit": envía el formulario (por defecto dentro de un form) --> <button type="submit">Enviar formulario</button> <!-- type="button": acción personalizada con JavaScript --> <button type="button">Haz clic aquí</button> <!-- type="reset": limpia todos los campos del formulario --> <button type="reset">Limpiar formulario</button> <!-- Botón desactivado --> <button type="button" disabled>No disponible</button> <!-- Botón con ícono (HTML dentro del button) --> <button type="button"> ❤️ Me gusta </button> <!-- IMPORTANTE: sin CSS, el botón tiene estilos del navegador --> <!-- Con CSS puedes darle cualquier apariencia -->
HTML

Con estilos CSS aplicados:

🟢 Siempre especifica el type en los botones

Dentro de un <form>, un botón sin type se comporta como type="submit" por defecto — puede enviar el formulario accidentalmente. Siempre escribe el type explícitamente: type="button" para acciones JS, type="submit" para enviar.

Listas — ul, ol y dl
Tres tipos de listas para tres situaciones distintas

HTML tiene tres tipos de listas. Cada elemento de la lista va dentro de una etiqueta <li> (list item) y las listas pueden anidarse unas dentro de otras.

<!-- LISTA NO ORDENADA (unordered list) — con viñetas --> <!-- Para elementos sin orden específico --> <ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul> <!-- LISTA ORDENADA (ordered list) — con números --> <!-- Para pasos, rankings, instrucciones secuenciales --> <ol> <li>Instala VS Code</li> <li>Crea index.html</li> <li>Escribe tu HTML</li> </ol> <!-- LISTA ANIDADA: lista dentro de otra lista --> <ul> <li>Frontend <ul> <li>HTML</li> <li>CSS</li> </ul> </li> <li>Backend</li> </ul> <!-- LISTA DE DEFINICIÓN: término + descripción --> <dl> <dt>HTML</dt> <dd>HyperText Markup Language — el lenguaje de la web</dd> <dt>CSS</dt> <dd>Cascading Style Sheets — los estilos visuales</dd> </dl>

🟢 Las listas tienen muchos usos con CSS

Los navbars de las webs son casi siempre un <ul> con <li> y links dentro. Con CSS puedes quitarle las viñetas (list-style: none), ponerlos en fila (display: flex) y darles cualquier apariencia. La etiqueta es semántica, la apariencia es CSS.

Atributos de <ol>

<!-- Empezar desde un número diferente --> <ol start="5"> <li>Este será el 5</li> <li>Este será el 6</li> </ol> <!-- Orden inverso --> <ol reversed> <li>Tercer lugar</li> <li>Segundo lugar</li> <li>Primer lugar</li> </ol> <!-- Tipo de numeración --> <ol type="A"> <!-- A, B, C... --> <ol type="i"> <!-- i, ii, iii... --> <ol type="1"> <!-- 1, 2, 3... (por defecto) -->

Tablas — <table>
Para datos tabulares: filas, columnas, cabeceras y pie

Las tablas HTML son para mostrar datos en formato de filas y columnas — como una hoja de cálculo. La estructura tiene varias etiquetas que trabajan juntas.

<table> <!-- thead: cabecera de la tabla --> <thead> <tr> <!-- tr = table row (fila) --> <th>Jugador</th> <!-- th = table header (celda de cabecera) --> <th>Equipo</th> <th>Goles</th> </tr> </thead> <!-- tbody: cuerpo de la tabla --> <tbody> <tr> <td>Haaland</td> <!-- td = table data (celda de datos) --> <td>Man City</td> <td>36</td> </tr> <tr> <td>Mbappé</td> <td>Real Madrid</td> <td>28</td> </tr> </tbody> <!-- tfoot: pie de tabla --> <tfoot> <tr> <td colspan="2">Total goles</td> <!-- colspan: celda que ocupa 2 columnas --> <td>64</td> </tr> </tfoot> </table>

Las etiquetas de la tabla

EtiquetaQué esNota
<table>Contenedor de toda la tablaRaíz — todo va dentro
<thead>Cabecera — la fila de títulosOpcional pero recomendado
<tbody>Cuerpo — los datos principalesPuede haber varios tbody
<tfoot>Pie — totales o resúmenesOpcional
<tr>Table Row — una filaVa dentro de thead, tbody o tfoot
<th>Table Header — celda de cabeceraEn negrita y centrado por defecto
<td>Table Data — celda de datosEl contenido real
colspan="N"La celda ocupa N columnasComo merge horizontal en Excel
rowspan="N"La celda ocupa N filasComo merge vertical en Excel

⚠️ Tablas solo para datos tabulares

Un error histórico muy común fue usar tablas para hacer el layout (la estructura) de las páginas web. No hagas esto. Las tablas son solo para datos que tienen sentido en filas y columnas (como una tabla de precios, una lista de partidos o un horario). Para el layout, usa CSS Flexbox o Grid.

🟢 Resumen de la Parte D

  • <form action method> — el contenedor del formulario. POST para datos sensibles.
  • <label for="id"> — siempre vinculada al input. Mejora accesibilidad y usabilidad.
  • <input type="..."> — auto-cierre. El type cambia todo: text, email, password, number, date, checkbox, radio.
  • <select> + <option> — lista desplegable. selected para el valor por defecto.
  • <textarea> — texto largo multilínea. No es auto-cierre.
  • Atributos útiles: placeholder, required, disabled, readonly, value, min, max, maxlength, autofocus.
  • <button type="submit|button|reset"> — siempre especifica el type.
  • <ul> — lista con viñetas, sin orden específico.
  • <ol> — lista numerada, para pasos o ranking. Atributos: start, reversed, type.
  • <li> — item de lista. Va dentro de ul u ol.
  • <dl> + <dt> + <dd> — lista de definiciones: término + descripción.
  • Tablas: table → thead/tbody/tfoot → tr → th/td. colspan y rowspan para combinar celdas.
  • Las tablas son solo para datos tabulares, nunca para layout de página.
