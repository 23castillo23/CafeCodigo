<hr> — Línea horizontal separadora
Divide visualmente secciones de contenido

La etiqueta <hr> (Horizontal Rule) dibuja una línea horizontal que separa secciones de contenido. Es una etiqueta de auto-cierre — no necesita etiqueta de cierre.

<p>Primera sección de contenido.</p> <hr> <!-- Línea separadora — sin etiqueta de cierre --> <p>Segunda sección de contenido.</p>
HTML

Primera sección de contenido.

Segunda sección de contenido.

🟢 hr es semántico, no solo visual

Aunque visualmente es una línea, semánticamente indica un cambio de tema en el contenido. Los lectores de pantalla lo anuncian como una separación. Para hacer líneas decorativas con CSS usa border en lugar de <hr>.

Comentarios — Notas en el código que nadie ve
Texto invisible para el usuario, visible solo en el código fuente

Los comentarios son texto que escribes en el código HTML pero que el navegador ignora completamente. Solo tú (y otros desarrolladores) los ven al ver el código fuente. Son útiles para explicar qué hace una sección, dejar notas, o desactivar código temporalmente.

<!-- Esto es un comentario — el navegador no lo muestra --> <h1>Título visible</h1> <!-- TODO: agregar imagen aquí después --> <!-- Los comentarios pueden ocupar varias líneas --> <!-- <p>Este párrafo está desactivado temporalmente</p> -->
HTML

Título visible

(Los comentarios no aparecen aquí — solo en el código fuente)

⚠️ Los comentarios NO son seguros para información privada

Aunque el usuario no los ve en la pantalla, cualquiera puede verlos haciendo clic derecho → "Ver código fuente". Nunca pongas contraseñas, tokens o información sensible en comentarios HTML.

🟢 Atajo en VS Code

Selecciona el texto que quieres comentar y presiona Ctrl + / (Windows/Linux) o Cmd + / (Mac). VS Code agrega o quita los comentarios automáticamente.

<span> — Marcar partes de texto inline
El contenedor invisible para aplicar estilos a palabras específicas

<span> es un contenedor inline sin estilo propio — no hace nada visible por sí solo. Su utilidad es envolver palabras o frases específicas dentro de un texto para poder aplicarles estilos CSS o identificarlas con JavaScript.

<!-- Sin span: no puedo darle color solo a una palabra --> <p>Este texto es normal y no tiene color especial.</p> <!-- Con span: puedo aplicar CSS a palabras específicas --> <p> Este texto es <span style="color: blue">azul</span> y esto es <span style="color: red; font-weight: bold">rojo y negrita</span>. </p> <!-- Con clase CSS (la forma correcta en proyectos reales) --> <p> El precio es <span class="precio-destacado">$99 MXN</span>. </p>
HTML

Este texto es azul y esto es rojo y negrita.

El precio es $99 MXN.

span vs div — la diferencia clave

<span> — Inline

Va dentro de un párrafo o texto. No rompe el flujo del texto — todo sigue en la misma línea.

Para: palabras, frases, íconos dentro de texto

<div> — Block

Crea un bloque nuevo que ocupa todo el ancho disponible. Rompe el flujo — lo siguiente va en la siguiente línea.

Para: secciones, contenedores, grupos de elementos

<br> — Salto de línea
Fuerza un salto de línea dentro de un bloque de texto

<br> (break) fuerza un salto de línea en el punto donde se coloca. Es de auto-cierre. Úsalo cuando el salto de línea es parte del contenido (una dirección, un poema), no para crear espacio entre elementos.

<!-- Caso de uso correcto: dirección donde los saltos importan --> <p> Calle Falsa 123<br> Colonia Centro<br> Orizaba, Veracruz<br> México </p> <!-- Caso de uso correcto: poema o letra de canción --> <p> En el principio era el código,<br> y el código estaba con HTML,<br> y el HTML era la web. </p> <!-- ❌ Mal uso: usar <br> para separar párrafos --> <p>Primer párrafo.</p> <br><br> <!-- MAL — usa otro <p> en su lugar --> <p>Segundo párrafo.</p>
HTML

Calle Falsa 123
Colonia Centro
Orizaba, Veracruz
México

⚠️ No abuses del <br>

Un error común es usar <br><br> para crear espacio entre párrafos. La forma correcta es usar dos etiquetas <p> separadas — el navegador les agrega espacio automáticamente, y con CSS tienes control total sobre ese espacio.

<a> — Hipervínculos
La etiqueta que conecta páginas — el corazón de la web

La etiqueta <a> (anchor) crea un hipervínculo — un texto o elemento en el que el usuario puede hacer clic para ir a otro lugar. El atributo href (Hypertext REFerence) define el destino.

<!-- Enlace externo: URL completa --> <a href="https://www.google.com">Ir a Google</a> <!-- Enlace interno: ruta relativa a otro archivo --> <a href="contacto.html">Página de contacto</a> <a href="../index.html">Volver al inicio</a> <!-- Abrir en nueva pestaña --> <a href="https://github.com" target="_blank" rel="noopener noreferrer"> Mi GitHub </a> <!-- Descargar un archivo --> <a href="cv.pdf" download>Descargar mi CV</a> <!-- Ancla: saltar a una sección de la misma página --> <a href="#contacto">Ir a Contacto</a> <!-- El destino: --> <section id="contacto">...</section> <!-- Link de email --> <a href="mailto:hugo@email.com">Envíame un email</a> <!-- Link de teléfono --> <a href="tel:+527201234567">Llámame</a>
HTML
Ir a Google (enlace externo) Página de contacto (enlace interno) Mi GitHub (abre en nueva pestaña) Descargar mi CV (download)

Los atributos más importantes de <a>

href
El destino del enlace. URL completa, ruta relativa, ancla o protocolo especial.
href="https://..." / href="pagina.html" / href="#seccion"
target="_blank"
Abre el enlace en una nueva pestaña del navegador.
Siempre acompañar con rel="noopener noreferrer"
rel="noopener"
Seguridad: evita que la página destino pueda acceder a tu página cuando se abre en nueva pestaña.
Obligatorio con target="_blank"
download
En vez de navegar al archivo, lo descarga. Funciona con PDFs, imágenes, etc.
download / download="nombre-archivo.pdf"

Rutas relativas vs absolutas

<!-- RUTA ABSOLUTA: URL completa incluyendo el protocolo --> <a href="https://www.google.com/maps">Google Maps</a> <!-- RUTA RELATIVA: desde la ubicación del archivo actual --> <!-- Si estás en index.html y quieres ir a: --> <a href="contacto.html">contacto.html en la misma carpeta</a> <a href="paginas/about.html">about.html en subcarpeta</a> <a href="../index.html">index.html en la carpeta padre (../ = subir un nivel)</a>
HTML

🟢 Cuándo usar ruta relativa vs absoluta

  • Ruta relativa: para links dentro de tu mismo proyecto (entre páginas de tu web). Si mueves el proyecto a otro servidor, siguen funcionando.
  • Ruta absoluta: para links a otras páginas web externas. Siempre con https://.

<img> — Imágenes
Mostrar imágenes en la página — auto-cierre, src y alt obligatorios

La etiqueta <img> inserta una imagen en la página. Es de auto-cierre — no tiene etiqueta de cierre. Sus dos atributos más importantes son src (la ruta de la imagen) y alt (descripción de la imagen).

<!-- Imagen local (en tu proyecto) --> <img src="img/coffee.png" alt="Taza de café humeante"> <!-- Imagen desde internet (URL externa) --> <img src="https://via.placeholder.com/400x300" alt="Imagen de ejemplo"> <!-- Con tamaño definido --> <img src="img/coffee.png" alt="Café de la mañana" width="400" height="300" > <!-- Imagen como enlace: <img> dentro de <a> --> <a href="https://google.com"> <img src="img/logo.png" alt="Logo — ir al inicio"> </a>
HTML

Imagen con tamaño definido:

☕ coffee.png

Si la imagen no carga, muestra el alt:

🖼 Taza de café humeante

El atributo alt — no es opcional

SituaciónQué escribir en alt
Imagen con información importanteDescripción clara: "Gráfica de barras mostrando ventas de enero a junio"
Imagen decorativa (solo visual)Alt vacío: alt="" — el lector de pantalla la ignora
Imagen que es un enlaceDescribe el destino: "Logo — ir a la página de inicio"
Imagen que es un botónDescribe la acción: "Botón de buscar"

⚠️ Nunca omitas el alt

El atributo alt es obligatorio en todas las imágenes. Sin él, los lectores de pantalla leen el nombre del archivo (horrible experiencia) y Google no puede indexar la imagen. Si la imagen es solo decorativa, usa alt="" vacío — nunca omitas el atributo.

Formatos de imagen para la web

.jpg / .jpeg

Fotos. Compresión alta, no soporta transparencia.

.png

Imágenes con transparencia. Logos, iconos, ilustraciones.

.webp

Moderno, pesa menos que jpg y png. El más recomendado hoy.

.svg

Vectorial: escala sin perder calidad. Perfecto para logos e iconos.

.gif

Imágenes animadas. Hoy se prefiere video MP4 o WebP animado.

✏️ Ejercicio Parte C — Links e imágenes Principiante

Sigue construyendo tu index.html del ejercicio anterior. Agrega lo siguiente:

  1. Una <hr> para separar la sección "Sobre mí" de "Lo que estoy aprendiendo".
  2. Un comentario encima de cada sección: <!-- SECCIÓN: Sobre mí -->
  3. En uno de tus párrafos, usa <span style="color:..."> para destacar una palabra con color.
  4. Agrega una dirección o cualquier texto que necesite saltos de línea usando <br>.
  5. Agrega al menos 3 links:
    • Uno externo a un sitio que uses (YouTube, GitHub, etc.)
    • Uno que abra en nueva pestaña con target="_blank" y rel="noopener noreferrer"
    • Uno de correo con mailto:
  6. Crea una carpeta img dentro de tu proyecto y guarda ahí una imagen (puede ser cualquier foto tuya o de lo que quieras).
  7. Muestra esa imagen en la página con <img src="img/tu-foto.jpg" alt="descripción">.
  8. Agrega width="300" a la imagen para que no ocupe toda la pantalla.

Bonus: Envuelve tu imagen en un <a> para que al hacer clic en ella lleve al usuario a tu perfil de GitHub o red social.

🟢 Resumen de la Parte C

  • <hr> — línea horizontal separadora, auto-cierre, semántica de cambio de tema
  • <!-- comentario --> — invisible para el usuario, visible en código fuente. Atajo: Ctrl+/
  • <span> — contenedor inline sin estilo propio, para aplicar CSS a palabras específicas
  • <br> — salto de línea, auto-cierre. Úsalo solo cuando el salto es parte del contenido
  • <a href="..."> — hipervínculo. href puede ser URL, ruta relativa, ancla, mailto o tel
  • target="_blank" + rel="noopener noreferrer" — para abrir en nueva pestaña de forma segura
  • download — para que el link descargue el archivo en vez de abrirlo
  • <img src="..." alt="..."> — imagen, auto-cierre. src=ruta, alt=descripción obligatoria
  • Formatos: jpg (fotos), png (transparencia), webp (moderno y ligero), svg (vectorial), gif (animado)
