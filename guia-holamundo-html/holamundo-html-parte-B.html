DOCTYPE — La primera línea de todo archivo HTML
Le avisa al navegador qué versión de HTML estás usando

El <!DOCTYPE html> siempre va en la primera línea del archivo, antes de cualquier otra cosa. No es una etiqueta HTML, es una declaración que le dice al navegador: "este archivo es HTML5, renderízalo correctamente".

<!-- Primera línea obligatoria de todo archivo HTML --> <!DOCTYPE html> <!-- No lleva etiqueta de cierre --> <!-- No distingue mayúsculas (pero la forma estándar es minúsculas) --> <!-- En HTML5 es simplemente "html" — en versiones anteriores era más largo -->
HTML
❌ HTML antiguo (antes de HTML5)
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd">

Largo, difícil de recordar y diferente según la versión

✅ HTML5 (lo que usamos hoy)
<!DOCTYPE html>

Simple, corto y fácil de recordar. HTML5 es el estándar actual.

💡
Si olvidas el DOCTYPE, el navegador entra en "quirks mode" (modo de compatibilidad antigua) y puede renderizar tu página de forma incorrecta. Siempre ponla.
🌐
<html> — El elemento raíz
El contenedor que envuelve absolutamente todo el documento

Después del DOCTYPE viene <html> — es el elemento raíz que contiene todo lo demás. El atributo más importante que lleva es lang, que indica el idioma del contenido.

<!-- El atributo lang es importante para accesibilidad y SEO --> <html lang="es"> <!-- Español --> <html lang="en"> <!-- Inglés --> <html lang="es-MX"> <!-- Español de México --> <html lang="pt-BR"> <!-- Portugués de Brasil -->
HTML

🟢 ¿Por qué importa el atributo lang?

  • Los lectores de pantalla lo usan para pronunciar el texto correctamente
  • Google lo usa para saber en qué idioma está la página
  • El navegador puede ofrecer traducción automática basada en este atributo
🧠
<head> — La cabeza del documento
Información para el navegador que el usuario NO ve directamente

El <head> es como las instrucciones traseras de un libro — el usuario no las lee, pero son esenciales para que todo funcione. Aquí va la configuración de la página.

<head> <meta charset="UTF-8">Codificación — permite acentos y ñ <meta name="viewport" content="width=device-width, initial-scale=1.0">Responsive en móviles <title>Mi página</title>Texto de la pestaña del navegador <link rel="stylesheet" href="style.css">Enlaza el archivo CSS </head>
Etiqueta / atributoQué hace¿Obligatorio?
<meta charset="UTF-8">Define la codificación de caracteres. UTF-8 soporta acentos, ñ, emojis y cualquier idioma.Sí, siempre
<meta name="viewport">Hace que la página se vea bien en móviles y tablets. Sin esto todo se ve muy pequeño en celular.Sí, siempre
<title>Texto que aparece en la pestaña del navegador y en los resultados de Google.Sí, siempre
<link rel="stylesheet">Conecta un archivo CSS externo para dar estilos a la página.Cuando uses CSS externo
<meta name="description">Descripción que Google muestra bajo el título en los resultados de búsqueda.Recomendado para SEO

⚠️ Importante

Todo lo que está en el <head> es invisible para el usuario en la página. Si pones texto dentro del head, no aparecerá. El contenido visible siempre va en el <body>.

👁️
<body> — El cuerpo visible de la página
Todo lo que el usuario ve va aquí — sin excepción

El <body> es donde vive todo el contenido visible: textos, imágenes, botones, formularios, links, videos… absolutamente todo lo que el usuario puede ver e interactuar.

<body> <!-- Todo esto es visible en el navegador --> <h1>Título principal</h1> <p>Un párrafo de texto</p> <img src="foto.jpg" alt="descripción"> <a href="https://google.com">Ir a Google</a> </body>

<title> — El nombre de la pestaña
Lo que aparece en la pestaña del navegador y en Google

La etiqueta <title> va dentro del <head> y define el texto que aparece en la pestaña del navegador. También es lo que Google muestra como título en los resultados de búsqueda.

<head> <title>Mi primera web — Hugo</title> </head>
HTML

Así se ve en la pestaña del navegador:

🌐 Mi primera web — Hugo ✕
contenido de la página…

🟢 Buenas prácticas para el title

  • Describe claramente qué es la página — no uses solo "Inicio" o "index"
  • Máximo 60 caracteres para que no se corte en Google
  • Patrón común: Nombre de la página — Nombre del sitio
📐
Títulos h1–h6 — La jerarquía del contenido
Seis niveles de encabezado para organizar la información

HTML tiene 6 niveles de títulos, del <h1> al <h6>. El número indica la jerarquía: h1 es el más importante y grande, h6 el menos importante y pequeño. Los usa el navegador, los lectores de pantalla y Google para entender la estructura del contenido.

<h1>Título principal — solo uno por página</h1> <h2>Sección principal</h2> <h3>Subsección</h3> <h4>Subsección de nivel 4</h4> <h5>Subsección de nivel 5</h5> <h6>Subsección de nivel 6</h6>
HTML
h1 Chanchito Felipe ~32px
h2 Chanchito Felipe ~24px
h3 Chanchito Felipe ~18.7px
h4 Chanchito Felipe ~16px
h5 Chanchito Felipe ~13.3px
h6 Chanchito Felipe ~10.7px

Estos son los tamaños por defecto del navegador. Con CSS puedes cambiarlos a lo que quieras.

Reglas importantes de los headings

❌ Mal uso
<!-- Dos h1 en la misma página --> <h1>Mi Blog</h1> <h1>Sobre mí</h1> <!-- Saltar niveles --> <h1>Título</h1> <h4>Subtítulo</h4>
✅ Buen uso
<!-- Un solo h1 --> <h1>Mi Blog</h1> <!-- Jerarquía ordenada --> <h2>Sobre mí</h2> <h3>Mi historia</h3> <h3>Mis hobbies</h3>

⚠️ La regla del h1

Solo debe haber un h1 por página. Es el título principal — como el título de un libro. El resto del contenido se organiza con h2, h3, etc. Tener varios h1 confunde a Google y a los lectores de pantalla.

🟢 Los headings no son para hacer texto grande

Un error muy común de principiantes es usar <h3> solo porque quieren texto de cierto tamaño. Los headings son semánticos — indican jerarquía de contenido, no tamaño visual. Para cambiar el tamaño del texto usa CSS. Usa los headings según su significado en la estructura del contenido.

📝
<p> — Párrafos de texto
La etiqueta más usada para mostrar texto en la web

La etiqueta <p> define un párrafo de texto. El navegador automáticamente agrega un espacio arriba y abajo de cada párrafo para separarlos visualmente.

<p>Chanchito feliz está muy feliz.</p> <p>Chanchito triste está muy triste.</p> <!-- Cada <p> crea un bloque separado --> <!-- El navegador agrega margen arriba y abajo automáticamente -->
HTML

Chanchito feliz está muy feliz.

Chanchito triste está muy triste.

El comportamiento del texto en HTML — algo que sorprende

En HTML, los espacios en blanco y los saltos de línea en el código no se respetan en el navegador. Puedes escribir el texto en varias líneas en tu editor, pero el navegador lo junta todo en una sola línea.

❌ Lo que escribes en el código
<p> Este texto tiene muchos saltos de línea en el código. </p>
✅ Lo que el navegador muestra
Este texto tiene muchos saltos de línea en el código.

El navegador ignora los saltos de línea del código y junta todo

⚠️ Si quieres un salto de línea dentro de un párrafo

Usa la etiqueta <br> (break). Pero úsala con moderación — para saltos de línea dentro de un mismo bloque de contenido (como una dirección o un poema), no para crear separación entre párrafos. Para eso, usa dos etiquetas <p> separadas.

Resumen visual — la estructura completa hasta aquí

<!DOCTYPE html> <html lang="es"> <head> <!-- invisible para el usuario --> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Mi primera web</title> </head> <body> <!-- todo lo que el usuario VE --> <h1>Chanchito Felipe</h1> <!-- solo un h1 --> <h2>Su historia</h2> <p>Chanchito feliz está muy feliz.</p> <p>Chanchito triste está muy triste.</p> </body> </html>
