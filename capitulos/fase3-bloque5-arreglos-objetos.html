Antes de empezar: recordatorio rápido
Lo que ya sabes de los bloques anteriores

Ya sabes variables, condicionales, bucles y funciones. Hasta ahora cada variable guarda UN solo dato. ¿Qué pasa si quieres guardar una lista de 20 tareas, o los datos de un contacto (nombre, teléfono, correo)? Para eso existen los arreglos y los objetos.

📖
Vocabulario nuevo
Dos formas distintas de agrupar datos

🧠 Piénsalo así

Un arreglo es como un estante de libros numerado: el libro 0, el libro 1, el libro 2... el orden importa y accedes por número de posición. Un objeto es como una ficha de contacto: no hay "primero" ni "segundo", cada dato tiene su propia etiqueta con nombre (nombre, teléfono, correo).

🧺
Arreglo (array)
Una lista ORDENADA de valores
🔢
Índice
La posición de un elemento en el arreglo — SIEMPRE empieza en 0
🗂
Objeto
Datos agrupados con nombre (propiedades), sin orden fijo
🏷
Propiedad
Cada par nombre: valor dentro de un objeto
🧺
PARTE 1 — Arreglos
Prueba agregar, quitar y acceder por índice en vivo
JSlet bebidas = ["Café", "Té", "Chocolate"]; console.log(bebidas[0]); // "Café" console.log(bebidas.length); // 3
Parte¿Qué hace?
[ ]Los corchetes crean el arreglo, con los valores separados por comas.
bebidas[0]Accede al PRIMER elemento — los índices empiezan en 0, no en 1.
.lengthTe dice cuántos elementos tiene el arreglo.

⚠️ El índice empieza en 0

Es el error de principiante más común: bebidas[1] te da el SEGUNDO elemento ("Té"), no el primero. El último elemento está en la posición length - 1.

bebidas[] → "Café"
🔂
PARTE 2 — Recorrer un arreglo
Combina lo que ya sabes de bucles con tu nuevo arreglo
JSlet bebidas = ["Café", "Té", "Chocolate"]; for (let i = 0; i < bebidas.length; i++) { console.log(bebidas[i]); }

💡 Por qué i < bebidas.length

Usar .length en la condición (en vez de escribir "3" directamente) hace que tu bucle funcione SIEMPRE, aunque el arreglo cambie de tamaño después — nunca vas a tener que actualizar ese número a mano.

🗂
PARTE 3 — Objetos
Haz clic en cada propiedad para ver cómo se accede a ella
JSlet contacto = { nombre: "Jacqui", telefono: "272-555-0000", activo: true }; console.log(contacto.nombre); // "Jacqui"
Parte¿Qué hace?
{ }Las llaves crean el objeto.
nombre: "Jacqui"Una propiedad: el nombre a la izquierda, el valor a la derecha, separados por dos puntos.
contacto.nombreEl punto accede a una propiedad por su nombre — no por número, como en los arreglos.
