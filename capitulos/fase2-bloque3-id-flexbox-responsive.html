Antes de empezar: recordatorio rápido
Lo que ya sabes de los bloques anteriores

Ya sabes usar selectores de etiqueta (p) y de clase (.destacado), darles color con color/background-color, y controlar el espacio con margin, border y padding. Este es el último bloque de CSS — al terminarlo vas a poder acomodar varios elementos en fila o columna, y hacer que tu página se adapte a pantallas chicas.

PARTE 1 — El selector de id
Parecido a la clase, pero con una regla importante distinta
HTML<header id="principal">...</header>
CSS#principal { background-color: #16211d; }
SelectorSímbolo¿Cuántas veces se puede usar?
classpunto .Las veces que quieras, en varios elementos distintos.
idgato #UNA sola vez por página — identifica a un elemento único, como "el encabezado principal".

⚠️ Regla de oro

Si vas a reutilizar un estilo en varios elementos (varias tarjetas, varios botones), usa class. Usa id solo para algo que es único en la página, como el menú principal o el pie de página. Repetir el mismo id en dos elementos es un error, aunque el navegador no siempre te lo marque.

PARTE 2 — Flexbox: acomodar elementos
Prueba los controles y mira las cajas moverse en tiempo real

🧠 Piénsalo así

Un contenedor con display: flex es como una repisa: sus elementos se acomodan automáticamente en fila, uno junto al otro. Tú solo decides CÓMO se reparten el espacio — pegados a la izquierda, centrados, separados, etc. — sin calcular posiciones a mano.

.contenedor {
  display: flex;
  justify-content: flex-start;
  align-items: flex-start;
}
Propiedad¿Dónde se pone?¿Qué controla?
display: flexEn el contenedor (el padre)Activa el modo flexbox para sus hijos directos.
justify-contentEn el contenedorCómo se reparten los elementos en el eje horizontal (si flex-direction es row).
align-itemsEn el contenedorCómo se alinean los elementos en el eje vertical.
flex-directionEn el contenedorSi los elementos van en fila (row) o en columna (column).

💡 La regla clave de flexbox

Las propiedades display: flex, justify-content y align-items SIEMPRE se ponen en el elemento contenedor (el padre), nunca en los elementos de adentro. Es una confusión muy común al empezar — si no ves efecto, revisa que se lo pusiste al padre correcto.

📱
PARTE 3 — Responsive básico con media queries
Cambia entre vista de escritorio y celular con el botón
CSS.contenedor { display: flex; flex-direction: row; } /* Esta regla solo aplica si la pantalla mide 500px o menos */ @media (max-width: 500px) { .contenedor { flex-direction: column; } }
Parte¿Qué hace?
@mediaLe dice a CSS "esta regla de adentro solo aplica bajo cierta condición de pantalla".
(max-width: 500px)La condición: "cuando el ancho de la pantalla sea 500px o menos".

💡 Qué observar

En "Escritorio" las cajas están en fila. Al cambiar a "Celular", el ancho baja de 500px y la regla @media se activa sola, cambiando flex-direction a column — sin que tú tengas que hacer nada más. Así es como una misma página se adapta a distintos tamaños de pantalla.
