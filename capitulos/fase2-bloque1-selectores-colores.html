Antes de empezar: recordatorio rápido
Terminaste toda la Fase 1 — esto es lo que ya sabes construir

Ya sabes armar la estructura de una página con <section> y <div>, con títulos, párrafos, listas, enlaces e imágenes adentro. El problema: hasta ahora todo se ve "plano" — texto negro, sin colores ni espaciados. Eso es exactamente lo que CSS viene a resolver.

Vocabulario nuevo
Las palabras que vas a usar en cada línea de CSS

🧠 Piénsalo así

Si HTML es como los muebles de una casa (una mesa, una silla), CSS es la decoración: de qué color pintas cada mueble, qué tan grande lo haces, cuánto espacio dejas entre ellos. El mueble (HTML) sigue siendo el mismo — CSS solo cambia cómo se ve.

🏷

🎨

📏

PARTE 1 — Cómo conectar CSS a tu HTML
La forma más simple: escribirlo directo en el head

Por ahora vamos a escribir el CSS dentro de una etiqueta <style>, colocada en el <head> de tu documento:

HTML<head> <meta charset="UTF-8"> <title>Mi página</title> <style> /* aquí va todo tu CSS */ </style> </head>
Etiqueta¿Qué hace?
<style>Todo lo que escribas adentro se interpreta como CSS, no como HTML. Va dentro del <head>.

💡 ¿Y el archivo .css separado?

Más adelante, cuando tus páginas crezcan, vas a mover el CSS a un archivo aparte (ej. estilos.css) y conectarlo con <link rel="stylesheet" href="estilos.css">. Por ahora, usar <style> directo en el head es perfecto para aprender — es exactamente lo mismo, solo cambia dónde vive el código.

PARTE 2 — Selectores básicos
Cómo le dices a CSS A QUÉ elemento le hablas

Selector de etiqueta

Le aplica el estilo a TODAS las etiquetas de ese tipo en la página:

CSSp { color: blue; }
p { color: blue; }
selector
(a quién) propiedad
(qué cambio) valor
(a qué)
Parte¿Qué hace?
pEl selector — dice "esto le aplica a TODOS los <p> de la página".
{ }Las llaves envuelven todas las propiedades que le vas a dar a ese selector.
color: blue;Una declaración: la propiedad color con el valor blue. Siempre termina en punto y coma.

Selector de clase

Para aplicar un estilo solo a ALGUNOS elementos específicos, les pones una clase en el HTML:

HTML<p class="destacado">Este párrafo es especial</p>
CSS.destacado { color: red; }
Parte¿Qué hace?
class="destacado"En el HTML, le pones una etiqueta con nombre a un elemento específico.
.destacadoEn el CSS, el PUNTO antes del nombre le dice a CSS "esto es una clase, no una etiqueta". Solo afecta a los elementos que tengan class="destacado".

⚠️ El punto no es opcional

Si escribes destacado { color: red; } sin el punto, CSS va a buscar una etiqueta HTML llamada <destacado> (que no existe) y tu estilo simplemente no va a aplicar. El punto es lo que conecta con el atributo class.

PARTE 3 — Propiedades de color y tamaño
Las tres que más vas a usar al principio
CSSh1 { color: #4338ca; background-color: #eef0fd; font-size: 32px; }
Propiedad¿Qué controla?
colorEl color del TEXTO.
background-colorEl color de FONDO detrás del elemento.
font-sizeEl tamaño de la letra. px significa "píxeles", una unidad fija.

💡 Formas de escribir un color

  • Por nombre: blue, red, tomato — fácil de leer, pocas opciones.
  • Por código hexadecimal: #4338ca — el símbolo # seguido de 6 caracteres. Te da control exacto sobre el color. Es el que más vas a usar en proyectos reales.

💡 Qué observar

  • El botón de .destacado solo va a funcionar si ese elemento existe con esa clase en el HTML — fíjate que ya está puesta en uno de los párrafos.
