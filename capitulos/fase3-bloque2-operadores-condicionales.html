Vocabulario nuevo
Lo que necesitas para que tu código "pregunte" algo

🧠 Piénsalo así

Un condicional es como una señal de "si... entonces...": si llueve, entonces llevo paraguas; si no, lo dejo en casa. JavaScript funciona exactamente igual: evalúa una pregunta (¿llueve?), y según la respuesta (sí/no), ejecuta un bloque de código distinto.

⚠️ === vs ==

JavaScript también tiene == (dos signos), pero compara de forma "floja" — por ejemplo "5" == 5 da true, aunque uno sea texto y otro número. === (tres signos) es estricto y evita sorpresas. Usa siempre ===.

PARTE 2 — if / else
Cambia el número y mira qué camino del diagrama se ilumina
JSlet numero = 7; if (numero > 0) { console.log("Es positivo"); } else if (numero < 0) { console.log("Es negativo"); } else { console.log("Es cero"); }

else if (condición)Si la primera condición fue falsa, prueba con esta otra.
