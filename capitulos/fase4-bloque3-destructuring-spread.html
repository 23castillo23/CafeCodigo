Antes de empezar: recordatorio rápido
Lo que ya sabes de los bloques anteriores

Ya sabes crear objetos y arreglos, y acceder a sus datos con objeto.propiedad o arreglo[indice]. Este bloque te da dos atajos: uno para sacar varios datos de golpe (destructuring), y otro para copiar o combinar arreglos/objetos sin escribir un bucle (spread).

Dos símbolos que vas a ver constantemente

Destructuring
Sacar propiedades de un objeto (o elementos de un array) en variables, de un solo golpe
🌟
Spread (...)
"Desparrama" los elementos de un arreglo u objeto — para copiar o combinar

PARTE 1 — Destructuring de objetos
Haz clic en las propiedades que quieras "sacar" y mira el código generarse
JS — forma tradicionalconst contacto = { nombre: "Jacqui", edad: 25, ciudad: "Orizaba" }; const nombre = contacto.nombre; const edad = contacto.edad;
JS — destructuringconst { nombre, edad } = contacto;
Parte¿Qué hace?
{ nombre, edad }Crea DOS variables de golpe, con el MISMO nombre que las propiedades del objeto — así de simple.
= contactoEl objeto de donde se sacan esas propiedades.

💡 También funciona con arreglos

Con corchetes en vez de llaves, y por posición en vez de nombre: const [primero, segundo] = ["Café", "Té"]; — primero vale "Café", segundo vale "Té".

🌟
PARTE 2 — Spread (...)
Combina dos arreglos en uno solo
JSconst bebidasCalientes = ["Café", "Té"]; const bebidasFrias = ["Limonada", "Agua"]; const todas = [...bebidasCalientes, ...bebidasFrias]; console.log(todas); // ["Café", "Té", "Limonada", "Agua"]
Parte¿Qué hace?
...bebidasCalientesLos tres puntos "abren" el arreglo y vuelcan cada uno de sus elementos, en lugar del arreglo completo como una sola cosa.
[...a, ...b]Al poner ambos dentro de [ ], terminas con UN arreglo nuevo que contiene todos los elementos de los dos.
+
=

[...bebidasCalientes, ...bebidasFrias] → un solo arreglo con los 4 elementos

⚠️ También sirve para copiar sin modificar el original

const copia = [...original]; crea un arreglo NUEVO con los mismos elementos. Es distinto a const copia = original;, que NO copia — ambas variables terminarían apuntando al mismo arreglo, y cambiar una cambiaría la otra.

💡 Con objetos funciona igual, con { }

const copiaContacto = { ...contacto, edad: 26 }; — copia todas las propiedades de contacto, y sobrescribe edad con un valor nuevo. Muy usado para "actualizar" un objeto sin tocar el original.
