Vocabulario nuevo
La pieza que conecta todo

🧠 Piénsalo así

El DOM (Document Object Model) es como un mapa en vivo de tu página, que JavaScript puede leer y modificar. Es la diferencia entre el HTML que ESCRIBISTE (el plano de la casa) y la página que el usuario VE en su navegador (la casa ya construida, con muebles que se pueden mover).

⟡
DOM
La representación de tu página que JavaScript puede leer y cambiar
🎯
querySelector
El método para "encontrar" un elemento de tu HTML desde JavaScript
👆
Evento
Algo que pasa: un clic, escribir en un campo, cargar la página
👂
Listener
Código que "escucha" un evento y reacciona cuando ocurre

PARTE 1 — Seleccionar y cambiar elementos
El primer paso: encontrar el elemento que quieres modificar
HTML<h1 id="titulo">Hola</h1>
JSconst titulo = document.querySelector("#titulo"); titulo.textContent = "Hola, Jacqui"; titulo.style.color = "tomato";
Parte¿Qué hace?
documentRepresenta toda tu página HTML dentro de JavaScript.
querySelector("#titulo")Busca en el HTML el elemento que coincida con ese selector — usa la MISMA sintaxis de CSS que ya conoces (#id, .clase, etiqueta).
.textContentLee o cambia el texto de adentro del elemento.
.style.colorCambia un estilo CSS directamente desde JavaScript.

💡 ¿Ya conocías esta sintaxis?

Sí — querySelector("#titulo") y querySelector(".destacado") usan exactamente los mismos selectores que aprendiste en CSS. Eso no es casualidad: JavaScript reutiliza ese lenguaje para encontrar elementos.

👆
PARTE 2 — Reaccionar a eventos
Cómo hacer que algo pase cuando el usuario hace clic
JSconst boton = document.querySelector("#miBoton"); boton.addEventListener("click", function() { console.log("¡Me hicieron clic!"); });
Parte¿Qué hace?
addEventListener"Escucha" un tipo de evento en ese elemento.
"click"El tipo de evento — también existen "input" (al escribir), "submit" (al enviar un formulario), etc.
function() { ... }El código que se ejecuta CADA VEZ que ocurre el evento — la conectas con todo lo que ya sabes: variables, if, arrays.

⚠️ Espera a que la página cargue

Si tu <script> está en el <head> y trata de seleccionar un elemento que todavía no existe (porque el HTML de abajo aún no se cargó), querySelector va a devolver null y vas a tener un error. Por eso muchas veces el script se coloca al final del <body>, como en el laboratorio de abajo.
