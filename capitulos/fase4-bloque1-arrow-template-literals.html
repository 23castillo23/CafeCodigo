PARTE 1 — Arrow functions
Cambia entre las dos formas y compara
JS — forma tradicionalfunction sumar(a, b) { return a + b; }
JS — arrow functionconst sumar = (a, b) => a + b;
Cambio¿Qué pasó?
Se quita functionYa no se escribe la palabra function.
Se agrega =>La "flecha" va después de los parámetros — de ahí el nombre "arrow function".
Se quitan { } y returnSi la función es UNA sola línea que solo regresa un valor, puedes quitar las llaves y el return — el resultado se regresa automáticamente ("return implícito").

⚠️ ¿Cuándo SÍ necesitas las llaves?

Si tu función tiene MÁS de una línea (por ejemplo, un if adentro), sí necesitas { } y return explícito, igual que antes:

JSconst esMayorDeEdad = (edad) => { return edad >= 18; };

💡 ¿Debo dejar de usar function?

No es obligatorio — ambas formas funcionan igual. Pero las arrow functions son hoy el estilo más común, sobre todo para funciones cortas. Vale la pena que sepas LEERLAS aunque sigas escribiendo function cuando te sientas más cómoda.

🧵
PARTE 2 — Template literals
Escribe valores y mira el texto armarse en vivo
JS — forma tradicional (+)let nombre = "Jacqui"; let edad = 25; console.log("Hola, me llamo " + nombre + " y tengo " + edad + " años.");
JS — template literalconsole.log(`Hola, me llamo ${nombre} y tengo ${edad} años.`);
Parte¿Qué hace?
` `Comillas invertidas (backticks) — la tecla suele estar junto al 1, arriba del Tab. Reemplazan las comillas normales.
${ }Adentro de esto puedes poner CUALQUIER variable o expresión de JavaScript, y su valor se inserta directo en el texto.

💡 Por qué es mejor que +

Con + es fácil perder un espacio o una comilla. Con template literals escribes el texto casi normal, y solo marcas dónde va cada variable — más fácil de leer y de corregir.
