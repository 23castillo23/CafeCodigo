Antes de empezar: recordatorio rápido
Lo que ya sabes de los bloques anteriores

Ya sabes crear variables, comparar valores, usar if/else y repetir código con for. Ahora imagina que necesitas repetir ese MISMO bloque de lógica en varias partes distintas de tu programa, pero con datos diferentes cada vez. Copiar y pegar sería un desastre de mantener — para eso existen las funciones.

📖
Vocabulario nuevo
Cuatro palabras que van a aparecer todo el tiempo de aquí en adelante

🧠 Piénsalo así

Una función es como una máquina expendedora: le metes algo (una moneda, tu selección), la máquina hace su proceso interno, y te da un resultado. No te importa cómo funciona por dentro cada vez que la usas — solo le das lo que pide y recibes lo que devuelve.

ƒ
Función
Un bloque de código con nombre, que puedes usar ("llamar") cuando quieras
📥
Parámetro
El nombre que la función le da a los datos que recibe
📮
Argumento
El valor real que le pasas a la función cuando la usas
↩️
return
El resultado que la función te entrega de vuelta
ƒ
PARTE 1 — Declarar y usar una función
Dos pasos: crearla, y luego llamarla
JSfunction sumar(a, b) { return a + b; } console.log(sumar(3, 5)); // 8
Parte¿Qué hace?
functionLa palabra que le dice a JavaScript "voy a crear una función".
sumarEl nombre que tú eliges — así vas a "llamarla" después.
(a, b)Los parámetros: nombres para los datos que la función espera recibir.
return a + b;return entrega el resultado y TERMINA la función ahí mismo — nada después de un return se ejecuta.
sumar(3, 5)Aquí "llamas" a la función, pasándole 3 y 5 como argumentos — esos valores reales reemplazan a a y b.

⚠️ Parámetro vs argumento

Es una confusión común: a y b en la declaración son parámetros (nombres genéricos). 3 y 5 cuando la llamas son argumentos (valores reales). Es la misma idea, distinto momento.

💡 ¿Una función siempre necesita return?

No. Si solo quieres que HAGA algo (como imprimir un saludo) y no necesitas usar un resultado después, puedes omitir el return. Pero si vas a usar lo que la función calculó (como guardarlo en una variable), sí necesitas return.
