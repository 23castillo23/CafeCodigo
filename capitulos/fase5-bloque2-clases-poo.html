Antes de empezar: recordatorio rápido
Lo que ya sabes de objetos

Ya sabes crear un objeto directo: { nombre: "Jacqui", edad: 25 }. El problema es que, si necesitas crear 50 objetos "tarea" o "usuario" parecidos, escribirlos uno por uno a mano es repetitivo y propenso a errores. Una clase es un molde: la defines UNA vez, y después creas tantos objetos como quieras a partir de ella.

📖
Vocabulario nuevo
Cuatro palabras que definen la POO

🧠 Piénsalo así

Una clase es como el molde de las galletas: define la FORMA (qué propiedades va a tener toda galleta: sabor, tamaño). Cada galleta que sacas del molde es una instancia — todas comparten la misma forma, pero cada una puede tener su propio sabor.

⬡
class
El molde: define qué propiedades y comportamientos va a tener cada objeto
🏭
Instancia
Un objeto concreto creado a partir de la clase, con new
🛠
constructor
El método especial que se ejecuta al crear cada instancia nueva
👉
this
"Esta instancia en concreto" — se refiere al objeto que se está creando o usando
⬡
PARTE 1 — class y constructor
La sintaxis básica
JSclass Tarea { constructor(texto) { this.texto = texto; this.completada = false; } } const t1 = new Tarea("Estudiar JS"); console.log(t1.texto); // "Estudiar JS"
Parte¿Qué hace?
class TareaDefine el molde. Por convención, el nombre de una clase empieza con MAYÚSCULA.
constructor(texto)Se ejecuta automáticamente cada vez que creas una instancia nueva — recibe los datos iniciales.
this.texto = textothis es "esta tarea en particular". Le está diciendo: "guarda el parámetro texto como una propiedad DE ESTA instancia".
new Tarea("...")La palabra new es lo que realmente CREA la instancia — sin ella, Tarea(...) no funciona como esperas.

⚠️ No olvides new

Escribir Tarea("Estudiar") sin new da un error. new es la palabra que le dice a JavaScript "quiero una instancia nueva de este molde", no solo llamar la función.

🏭
PARTE 2 — Instanciador en vivo
Crea varias instancias de la misma clase y compáralas

Esta es la clase que vas a instanciar, tal cual, varias veces:

JSclass Tarea { constructor(texto, prioridad) { this.texto = texto; this.prioridad = prioridad; this.completada = false; } }

💡 Qué observar

Cada tarjeta de abajo es una instancia DISTINTA e INDEPENDIENTE, aunque todas vengan del mismo molde Tarea. Cambiar una no afecta a las demás — cada new Tarea(...) crea su propia copia de texto, prioridad y completada.

⚙️
PARTE 3 — Métodos: comportamiento dentro de la clase
No solo datos — también funciones que le pertenecen al objeto
JSclass Tarea { constructor(texto) { this.texto = texto; this.completada = false; } completar() { this.completada = true; } } const t1 = new Tarea("Estudiar"); t1.completar(); console.log(t1.completada); // true
Parte¿Qué hace?
completar() { }Un método — una función que vive DENTRO de la clase, disponible en cada instancia.
t1.completar()Se llama igual que cualquier método que ya conocías (como .push() o .map()) — porque, de hecho, son el mismo concepto.

💡 ¿Te suena familiar?

Sí — .push(), .map(), .toUpperCase() que ya usabas en arreglos y strings, son justamente métodos de las clases Array y String que ya vienen integradas en JavaScript. Ahora sabes cómo se construyen por dentro.
