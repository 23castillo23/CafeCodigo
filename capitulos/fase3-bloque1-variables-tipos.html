🧠 Piénsalo así

Una variable es como una caja de zapatos con una etiqueta pegada. La etiqueta es el nombre de la variable (por ejemplo, edad), y lo que guardas adentro de la caja es el valor (por ejemplo, 25). Cuando quieres usar ese dato después, solo buscas la caja por su nombre.

PARTE 1 — Crea tu primera variable
Dos formas de guardar un valor
JSlet miNombre = "Jacqui"; const meGustaProgramar = true;
Parte¿Qué hace?
letCrea una variable cuyo valor SÍ puede cambiar más adelante.
constCrea una variable cuyo valor NUNCA debe cambiar. Si lo intentas, JavaScript te da un error a propósito, como protección.
miNombreEl nombre que tú eliges para la variable. Sin espacios ni acentos.
=Aquí NO pregunta si son iguales — significa "asigna este valor a esta variable".
;Marca el final de la instrucción, como el punto final de una oración.

💡 ¿Cuál uso: let o const?

const es la opción por defecto en JavaScript moderno. Usa let solo cuando SEPAS que ese valor va a cambiar después (ej. un contador, una edad que aumenta).

PARTE 2 — Los tres tipos básicos
Todo valor en JavaScript "es" de un tipo, y eso importa
JS// number — un número, sin comillas let edad = 25; // string — texto, siempre con comillas let ciudad = "Orizaba"; // boolean — solo true o false let esDeNoche = false;
Tipo¿Cómo se ve?¿Para qué sirve?
number25, 3.14, -10Cantidades: edades, precios, resultados matemáticos.
string"Orizaba"Texto: nombres, mensajes. Siempre entre comillas.
booleantrue / falseSolo dos opciones — para responder preguntas de sí/no en el código.

⚠️ Un error muy común al empezar

"5" + "3" da como resultado "53" (dos textos que se pegan), pero 5 + 3 da 8 (dos números que se suman). Confundir número con texto es de los errores más frecuentes — pruébalo tú misma en el explorador de abajo.
