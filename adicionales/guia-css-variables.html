Introducción — variables reales, dentro del propio CSS
Nada de compilación, nada de build step

Las custom properties (comúnmente llamadas "CSS variables") permiten definir valores reutilizables directamente en CSS, sin necesitar un preprocesador como Sass. De hecho, este mismo sitio las usa para el botón de tema oscuro que acabas de probar arriba.

💡 La diferencia clave frente a Sass

Las variables de Sass se resuelven al compilar — una vez que el CSS llega al navegador, ya son solo valores fijos, como si nunca hubieran sido variables. Las custom properties de CSS existen en tiempo real dentro del navegador: pueden leerse y modificarse con JavaScript, y cambian instantáneamente todo lo que dependa de ellas.

🔤
Sintaxis básica
Dos guiones al declarar, var() al usar
:root { --color-primario: #c49a1a; --espaciado-base: 1rem; } .boton { background: var(--color-primario); padding: var(--espaciado-base) calc(var(--espaciado-base) * 2); }
ParteQué hace
--nombreDeclara una variable. El doble guion es obligatorio.
var(--nombre)Usa el valor de esa variable en cualquier propiedad CSS.
var(--nombre, valor)Segundo argumento opcional: valor de respaldo si la variable no existe.
/* Con valor de respaldo (fallback) */ .tarjeta { color: var(--color-texto, #1a1814); /* Si --color-texto no está definida, usa #1a1814 */ }
🌳
Alcance: :root vs. local
Las variables CSS respetan la cascada, igual que cualquier otra propiedad

Una custom property declarada en :root está disponible en toda la página. Pero también puedes declararla dentro de un selector específico, y solo ese elemento (y sus hijos) la verán con ese valor — sobrescribiendo la versión global solo en ese contexto.

:root { --color-acento: blue; /* valor global */ } .tarjeta-especial { --color-acento: hotpink; /* sobrescribe SOLO dentro de este elemento */ } .boton { background: var(--color-acento); /* será blue normalmente, pero hotpink dentro de .tarjeta-especial */ }

📢 Analogía: el anuncio de la oficina y la nota en tu escritorio

Una variable en :root es como un anuncio general que aplica a toda la oficina. Una variable declarada dentro de un componente específico es como una nota pegada solo en tu escritorio, que anula el anuncio general únicamente para ti — todos los demás siguen la regla general.

🟢 En la práctica, muchos proyectos usan ambas

Es común usar variables de Sass para valores que nunca cambian en tiempo real (como una escala tipográfica completa), y custom properties de CSS específicamente para lo que sí necesita cambiar dinámicamente — como un tema claro/oscuro o colores que varían por componente.

🎨
Theming en vivo, con JavaScript
Justo lo que usa el botón de tema oscuro de esta página

Prueba cambiando el color de esta tarjeta — cada clic actualiza una custom property con JavaScript, y todo lo que depende de ella (el borde, el punto y el texto) cambia instantáneamente:

--card-color: #c49a1a
// JavaScript: leer y modificar custom properties const tarjeta = document.querySelector('.demo-card'); // Modificar tarjeta.style.setProperty('--card-color', '#1a7a5a'); // Leer el valor actual const valorActual = getComputedStyle(tarjeta) .getPropertyValue('--card-color');

⚠️ getPropertyValue() devuelve texto, no siempre lo que esperas

El valor devuelto es una cadena de texto (a veces con espacios extra), no un color parseado o un número. Si necesitas usarlo en cálculos de JavaScript, tendrás que convertirlo o limpiarlo manualmente con .trim() u otras funciones.

Ejercicios
Para practicar lo que acabas de leer

Ejercicio 1 — Tu primera variable

Declara --espaciado: 1rem en :root y úsala en el padding y margin de tres elementos distintos de una página tuya.

Ejercicio 2 — Sobrescribe localmente

Crea una clase .tarjeta-destacada que redefina --color-acento solo dentro de ella, y comprueba que el resto de la página conserva el valor original.

Ejercicio 3 — Cambia un color con JS

Crea un botón que, al hacer clic, cambie una custom property de color con style.setProperty(), y verifica que todos los elementos que usan var() con esa variable cambien al instante.

💡 Para llevarte de esta guía

Las custom properties de CSS son variables reales del navegador: respetan la cascada y el alcance como cualquier otra propiedad, y —a diferencia de Sass— pueden leerse y modificarse en tiempo real con JavaScript. Son la base de casi cualquier sistema de theming dinámico moderno, este mismo sitio incluido.
