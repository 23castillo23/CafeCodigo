Introducción — layouts en dos dimensiones, por fin
Filas y columnas al mismo tiempo, sin trucos

CSS Grid es el sistema de layout de CSS pensado específicamente para organizar contenido en dos dimensiones a la vez: filas y columnas. A diferencia de Flexbox, que trabaja bien en una sola dirección, Grid te permite definir la estructura completa de una sección —cuántas columnas, cuántas filas, y dónde va cada bloque— desde un solo lugar.

💡 La idea central

Con Grid, defines una cuadrícula en el contenedor padre (display: grid) y luego colocas a los elementos hijos dentro de esa cuadrícula — ya sea dejando que fluyan automáticamente, o indicando exactamente en qué celda o área va cada uno.

🗂️ Analogía: el tablero de ajedrez

Flexbox es como acomodar objetos en una sola fila de estantería: puedes decidir su orden y espaciado, pero todo vive en una sola dirección. Grid es como un tablero de ajedrez: defines las filas y columnas de antemano, y cada pieza puede colocarse en una casilla específica, o incluso ocupar varias casillas a la vez.

Conceptos básicos

La unidad fr (fracción) es propia de Grid: representa una porción del espacio disponible, después de restar el gap y cualquier tamaño fijo. 1fr 1fr 1fr crea tres columnas de ancho idéntico que se reparten todo el espacio sobrante.

PropiedadQué define
grid-template-columnsEl número y tamaño de las columnas.
grid-template-rowsEl número y tamaño de las filas.
gapEl espacio entre celdas (equivalente a row-gap + column-gap).
minmax()Define un tamaño mínimo y máximo para una columna o fila, útil para diseños flexibles.

🟢 Un patrón muy común

grid-template-columns: repeat(3, 1fr); es exactamente lo mismo que escribir 1fr 1fr 1fr, pero más corto y más fácil de mantener si cambias el número de columnas.

🗺️
grid-template-areas: dibujar el layout con nombres
Probablemente la característica más querida de Grid

grid-template-areas te permite literalmente "dibujar" el layout usando nombres, y luego asignar cada elemento hijo a su área correspondiente con grid-area.

.layout { display: grid; grid-template-columns: 200px 1fr; grid-template-areas: "header header" "sidebar main" "footer footer"; } header { grid-area: header; } aside { grid-area: sidebar; } main { grid-area: main; } footer { grid-area: footer; }

🟢 Por qué esto resuelve el "Holy Grail Layout" de un plumazo

El clásico layout de encabezado + barra lateral + contenido + pie de página, que durante años fue tan difícil de lograr con tablas o floats (como se cuenta en la guía de "El caso de la etiqueta"), se resuelve con Grid en menos de diez líneas de CSS, sin trucos ni hacks.

🔀
auto-fit vs. auto-fill
El dúo que confunde a casi todo el mundo la primera vez

Ambos se usan junto con repeat() y minmax() para crear grids responsivos sin necesitar ni una sola media query:

.galeria { display: grid; grid-template-columns: repeat(auto-fit, minmax(180px, 1fr)); gap: 1rem; }

Esta única línea le dice al navegador: "crea tantas columnas de al menos 180px como quepan, y repártete el espacio sobrante entre ellas". Cuando la pantalla se achica, las columnas se reacomodan solas, sin que tengas que escribir un solo @media.

auto-fitauto-fill
Con pocos elementosEstira las columnas existentes para llenar el espacio sobrante.Deja columnas vacías "fantasma" del mismo tamaño, sin estirar las que sí tienen contenido.
Cuándo usarloCuando quieres que los elementos existentes aprovechen todo el ancho disponible.Cuando quieres mantener un tamaño de columna fijo, aunque sobre espacio vacío.

⚠️ La diferencia solo se nota con pocos elementos

Si tienes suficientes elementos para llenar todas las filas, auto-fit y auto-fill se ven exactamente igual. La diferencia solo se hace visible cuando hay espacio de sobra — por ejemplo, una galería con solo dos fotos en una pantalla ancha.

Alineación de items
justify vs. align, y por qué siempre se confunden
PropiedadEje que controlaAplica a
justify-itemsHorizontal (columnas)Todos los elementos hijos, dentro de su celda.
align-itemsVertical (filas)Todos los elementos hijos, dentro de su celda.
justify-contentHorizontalLa cuadrícula completa dentro del contenedor.
align-contentVerticalLa cuadrícula completa dentro del contenedor.

🟢 Truco para no confundirte

  • justify siempre es horizontal (como "justificar" texto de izquierda a derecha).
  • align siempre es vertical.
  • Si termina en -items, afecta a cada elemento individualmente dentro de su celda.
  • Si termina en -content, mueve la cuadrícula completa dentro del contenedor.

Ejercicios
Para practicar lo que acabas de leer

Ejercicio 1 — Galería responsiva

Crea una galería de 8 tarjetas usando grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));. Cambia el tamaño de tu ventana y observa cómo se reacomodan solas, sin ninguna media query.

Ejercicio 2 — El layout clásico

Recrea el layout de header + sidebar + main + footer mostrado arriba usando grid-template-areas, con tu propio contenido dentro de cada sección.

Ejercicio 3 — auto-fit vs auto-fill

Crea el mismo grid dos veces, uno con auto-fit y otro con auto-fill, pero coloca solo 2 elementos dentro. Compara visualmente la diferencia cuando sobra espacio.

💡 Para llevarte de esta guía

CSS Grid resuelve en pocas líneas lo que antes tomaba tablas anidadas o combinaciones frágiles de float. La combinación de grid-template-areas para la estructura y repeat(auto-fit, minmax(...)) para la responsividad cubre la gran mayoría de los layouts que vas a necesitar en proyectos reales.
